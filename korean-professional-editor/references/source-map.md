## 1. 결론

한국 비즈니스 문서에서 자연스럽게 읽히는 글은 구어체라서 자연스러운 것이 아니다. 다음 조건을 함께 만족한다.

1. 실제 주체와 행동이 보인다.
2. 한국어 어순으로 핵심이 앞에 나온다.
3. 명사 나열보다 조사와 동사로 관계를 설명한다.
4. 문서 유형에 맞는 정보 밀도와 격식을 지킨다.
5. 자기평가보다 역할·근거·결과를 제시한다.
6. 한 페이지나 한 항목에 핵심 메시지를 하나만 둔다.
7. 수치·인증·성과는 기준과 범위를 설명할 수 있다.
8. 완벽하게 대칭적인 문장보다 내용에 맞는 길이와 구조를 사용한다.

- 직무 포지셔닝, 경력, 프로젝트, 글이 같은 정체성을 증명해야 한다.

- 포트폴리오 페이지 제목과 본문 역할 구분
- 화면보다 문제와 판단을 먼저 쓰는 기준
- 프로젝트별 회고와 한계 서술

### 자료

- 투자자가 가장 궁금해할 문제와 증거를 앞쪽에 둔다.
- 첫 1~2페이지의 Executive Summary에서 핵심 쟁점을 요약한다.
- 회사마다 상황이 다르므로 고정 목차보다 투자 판단 질문에 맞춘다.

- `가능성`, `계획`, `계약`, `실적`을 같은 수준의 사실처럼 쓰지 않는다.

### 주의

민간 컨설팅사의 합격률·투자 성공률 등 홍보 수치는 스킬 기준으로 사용하지 않는다. 오래된 자료의 시장 수치보다 문서 역할과 투자자 의사결정 구조에 관한 원칙만 참고한다.

# 4. 한국어 AI 문체 연구

## 4.1 KatFishNet — 한국어 LLM 생성문 특성

### 논문

- [KatFishNet: Detecting LLM-Generated Korean Text through Linguistic Feature Analysis](https://aclanthology.org/2025.acl-long.1030/)

### 연구에서 다룬 특징

- 한국어 띄어쓰기 패턴
- 품사 조합의 다양성
- 쉼표 사용 빈도와 위치
- 사람 글과 LLM 글의 문장 구조 다양성 차이

### 이 스킬에서의 사용

- 문장 길이와 구조가 지나치게 균일한지 검사한다.
- 쉼표와 병렬 구조가 영어식으로 과도하게 사용되는지 본다.
- 단순히 어미만 바꾸는 방식이 아니라 문장 구조 자체를 다시 짠다.

### 사용하지 않는 방식

- AI 탐지 점수를 낮추기 위한 최적화
- 고의적인 띄어쓰기 오류나 문법 오류 삽입
- 특정 탐지기의 기준을 역이용한 우회

## 4.2 사람의 판별과 루브릭

### 논문

- [From Intuition to Expertise: Rubric-Based Cognitive Calibration for Human Detection of LLM-Generated Korean Text](https://arxiv.org/abs/2601.19913)

### 적용 원칙

- `AI 같다`는 감상 대신 구체적인 언어 특징을 기준으로 본다.
- 띄어쓰기, 문장 종결, 문체 전환, 구두점, 반복 구조를 분리해 점검한다.
- 최종 판단은 탐지 확률이 아니라 독자 이해와 문서 목적 달성으로 내린다.

# 5. 문서 유형별 코퍼스 선정 기준

## 이력서·경력기술서

우선순위:

1. 국내 채용 플랫폼의 공식 샘플
2. 현직자가 공개한 실제 이력서·경력기술서
3. 한국 기업의 채용·직무 인터뷰
4. 커리어 코치·헤드헌터의 공개 가이드

제외:

- 합격 보장을 내세운 템플릿 판매 페이지
- 직무·경력 수준이 다른 해외 이력서의 직역본
- 수치의 출처가 없는 성공 사례

## 포트폴리오

우선순위:

1. 직무 정체성과 프로젝트 판단 과정이 연결된 공개 사례
2. 실제 화면보다 문제·역할·결과가 먼저 보이는 사례
3. 프로젝트별 한계와 학습을 밝힌 사례

제외:

- 디자인만 화려하고 개인 책임이 보이지 않는 사례
- 결과 수치와 프로젝트 맥락이 분리된 사례
- 다른 작성자의 문장을 복제하게 만드는 템플릿

## IR·회사·제품 소개서

우선순위:

1. 회사가 직접 공개한 IR·주주서한·제품 소개
2. DART·기업 IR 사이트의 공식 자료
3. 공공 액셀러레이팅 프로그램의 가이드
4. 투자 실무 경험자가 공개한 자료 중 근거가 명확한 부분

제외:

- 투자 성공을 보장하는 상업 템플릿
- 기업의 자기 주장만 있고 근거가 없는 페이지
- 발표자의 구두 설명 없이는 이해되지 않는 슬라이드

## 브랜드 문서

우선순위:

1. 브랜드가 직접 운영하는 공식 사이트와 가이드
2. 여러 채널에서 같은 목소리를 유지하는 브랜드
3. 제품 행동과 약속이 연결된 카피

제외:

- 유명 브랜드 문구의 모방
- 감성만 남고 제품·행동이 없는 슬로건
- 업종과 고객이 다른 브랜드의 말투를 그대로 이식

# 6. 저작권·윤리 원칙

- 외부 자료의 전체 본문을 저장소에 복제하지 않는다.
- 짧은 원칙도 가능한 한 요약해 기록한다.
- 공개 사례의 문장·슬로건·페이지 디자인을 그대로 사용하지 않는다.
- 레퍼런스는 구조와 판단 기준을 배우는 데만 쓴다.
- 개인 이력서·포트폴리오의 이름, 연락처, 추천사는 재사용하지 않는다.
- 사용자 문서의 민감 정보는 익명화한다.
- 연구 결과는 자연스러운 한국어를 위한 진단에만 쓰고, AI 생성 사실을 숨기는 데 쓰지 않는다.

# 7. 업데이트 규칙

- 채용 플랫폼 구조나 기업 자료가 바뀌면 확인일을 갱신한다.
- 새로운 사례를 추가할 때는 `출처 수준`, `참고 범위`, `복제 금지 범위`를 함께 적는다.
- 개별 사례의 취향을 일반 원칙으로 승격하지 않는다.
- 서로 다른 출처에서 반복되는 원칙을 우선한다.
- 실제 스킬 사용 중 과잉 교정이 발견되면 사례를 `rewrite-examples.md`와 `quality-rubric.md`에 반영한다.
