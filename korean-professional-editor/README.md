# korean-professional-editor

한국의 채용·비즈니스 문서 문체에 맞춰 이력서, 경력기술서, 포트폴리오, IR, 회사·제품·브랜드 소개 자료를 자연스러운 한국어로 다시 쓰는 Claude Code 스킬이다.

## 해결하는 문제

AI 초안은 문법적으로 맞아도 다음 문제가 자주 남는다.

- `전환·연결·구체화·고도화` 같은 추상 동사의 반복
- `~를 통해`, `~에 대한`, `~기반`의 번역투
- 명사와 가운데점이 길게 이어지는 문장
- 모든 문장이 같은 길이와 `~했습니다`로 끝나는 리듬
- 실제 주체·책임·근거가 보이지 않는 `리드·총괄·기여`
- 이력서, 포트폴리오, IR에 같은 문체를 적용하는 문제
- 사람처럼 보이게 하려다 구어체·오류를 억지로 넣는 문제

이 스킬은 사실과 전문성을 보존하면서 문서 유형별로 문장 구조와 정보 우선순위를 다시 잡는다.

## 주요 트리거

- AI 티 빼줘
- 번역투 없애줘
- 사람이 쓴 것처럼 자연스럽게
- 이력서 문장 다듬어줘
- 경력기술서 자연스럽게
- 포트폴리오 카피 다듬기
- IR/PPT 문구 정리
- 제품 소개 문장을 담백하게
- 브랜드 소개가 너무 AI 같아

## 문서 유형

- 이력서: 5초 안에 직무·최근 책임·대표 증거가 보이게 편집
- 경력기술서: 문제·판단·개인 책임·일정·품질·리스크를 설명
- 포트폴리오: 결론형 제목과 `문제–근거–판단–실행–결과–학습` 흐름
- IR: 한 페이지 한 주장, 수치·기간·출처, 계획과 실적 분리
- 제품·서비스 소개: 기능보다 고객 상황과 변화를 먼저 제시
- 브랜드 소개: 빈 슬로건을 줄이되 기존 브랜드 목소리를 보존

## 기존 스킬과의 차이

| 스킬 | 역할 |
|---|---|
| `korean-professional-editor` | 한국 채용·사업 문서를 목적에 맞는 최종 문장으로 재작성 |
| `editorial-reviewer` | 모든 문서의 가독성·논리·용어·인용을 검토하고 수정점을 보고 |
| `general-ux-writing` | 버튼·오류 메시지·도움말 등 UI 마이크로카피 작성 |

권장 순서:

```text
사실·증거 확정
→ korean-professional-editor
→ editorial-reviewer
→ 맞춤법·PDF·레이아웃 검사
```

## 가드레일

- 없는 수치·성과·역할을 추가하지 않는다.
- 설계·프로토타입·실제 운영을 구분한다.
- 다른 사람의 문장이나 브랜드 목소리를 복제하지 않는다.
- AI 탐지 우회를 목표로 하지 않는다.
- 사람처럼 보이게 하려고 오탈자·비문·군더더기를 넣지 않는다.
