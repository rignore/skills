# 단위 경제성 벤치마크 및 자동 검증 공식

Phase 3에서 자동 적용되는 정량 가드레일의 상세 공식·벤치마크·해석.

## 1. LTV (Lifetime Value)

### 공식

```
LTV = (ARPA × Gross Margin) ÷ 월 이탈률
```

- ARPA: Average Revenue Per Account (월)
- Gross Margin: 매출 - COGS의 비율 (소수)
- 월 이탈률: Monthly Churn Rate (소수)

### 핵심 규칙

- **LTV는 반드시 Gross Profit 기준**. 매출(Revenue) 사용 시 수익성 과대 계상 → 자동 거부
- AI 추론 비용·인프라·고객 지원 인건비를 모두 차감한 진정한 Gross Margin 사용
- 이탈률은 자체 데이터 우선, 없으면 업계 평균 사용 (출처 명시)

### 업계 평균 이탈률

| 세그먼트 | 월 이탈률 | 연 이탈률 |
|---|---|---|
| Enterprise (ACV $50K↑) | 0.5~1% | 6~12% |
| Mid-market (ACV $5K~50K) | 1~2% | 12~24% |
| SMB (ACV $5K 미만) | 3~5% | 36~60% |

## 2. CAC (Customer Acquisition Cost) — Fully Loaded

### 공식

```
CAC = (마케팅비 + 영업·마케팅 인건비 + 영업 커미션 + 도구 비용 + 간접비 배분) ÷ 신규 고객 수
```

### 포함해야 할 항목 (누락 시 자동 거부)

| 항목 | 설명 |
|---|---|
| 마케팅비 | 광고, 콘텐츠 제작, 이벤트, 컨퍼런스 |
| 영업 인건비 | BDR, SDR, AE, CSM 인건비 |
| 마케팅 인건비 | 마케팅 매니저, 콘텐츠, 디자이너 |
| 영업 커미션 | 거래 성사 인센티브 |
| 영업 도구 | CRM, 인텔리전스, 자동화 도구 |
| 간접비 배분 | HR, 사무실, IT 인프라 (영업·마케팅 비율만큼) |

**광고비만 반영한 CAC = 보통 실제의 1/3** → 자동 거부 후 재산정 요구

## 3. LTV:CAC Ratio

### 공식

```
LTV:CAC = LTV ÷ CAC
```

### 통과 기준

| 비율 | 판정 | 해석 |
|---|---|---|
| < 1 | 🔴 차단 | 고객 획득 비용이 평생 가치보다 큼 — 사업 자체 무효 |
| 1~3 | 🔴 차단 | 단위 경제성 부족, 성장할수록 손실 |
| 3~4 | 🟡 경고 | 최소 기준 충족, 마진 여유 부족 |
| 4~7 | 🟢 통과 | 건강한 수준 |
| > 7 | 🟢 통과 (단 검증) | 매우 좋음, 단 CAC 산정 누락 의심 — 재검증 필요 |

## 4. CAC Payback Period

### 공식

```
CAC Payback (개월) = CAC ÷ (월 ARPA × Gross Margin)
```

### 통과 기준

| 세그먼트 | 통과 기준 | 해석 |
|---|---|---|
| SMB | ≤ 6개월 | 빠른 회수가 SMB 시장의 핵심 |
| Mid-market | ≤ 9개월 | 적정 |
| Enterprise | ≤ 12~18개월 | 긴 사이클 허용, 단 자금 압박 |

**18개월 초과 → 자금 경색 리스크 경고**, 24개월 초과 → 자동 차단

## 5. Rule of 40

### 공식

```
Rule of 40 (%) = 매출 성장률(%) + 영업 이익률(%)
```

### 통과 기준

| 값 | 판정 |
|---|---|
| ≥ 40% | 🟢 통과 |
| 30~40% | 🟡 경고 |
| < 30% | 🔴 차단 (가격·마진 방어 논리 요구) |

### 단계별 차등 적용

| ARR 규모 | 권장 Rule of 40 |
|---|---|
| < $10M | 60%↑ (성장 우선) |
| $10M~50M | 40%↑ |
| $50M~100M | 30%↑ (성장 둔화 자연) |
| > $100M | 25%↑ |

## 6. NRR (Net Revenue Retention)

### 공식

```
NRR (%) = (시작 MRR + 확장 MRR - 이탈 MRR - 다운셀 MRR) ÷ 시작 MRR × 100
```

### 통과 기준

| NRR | 판정 | 해석 |
|---|---|---|
| < 90% | 🔴 차단 | 기존 고객 풀이 줄어듦 |
| 90~100% | 🟡 경고 | 신규 고객 확보가 이탈을 겨우 보상 |
| 100~120% | 🟢 통과 | 건강 |
| ≥ 120% | 🟢 우수 | 확장 매출이 강력함 (Top-tier SaaS 수준) |

## 7. Gross Margin

### 공식

```
Gross Margin (%) = (매출 - COGS) ÷ 매출 × 100
```

### COGS 포함 항목

- 클라우드 인프라 (AWS, GCP, Azure)
- AI 추론 비용 (OpenAI, Anthropic API 등)
- 데이터베이스, CDN, 보안 도구
- 고객 지원 인건비 (CSM, 기술 지원)
- 데이터 라이선스 (외부 데이터 구매 시)

### 통과 기준

| 사업 유형 | 최소 Gross Margin | 우수 |
|---|---|---|
| 일반 SaaS | 70% | 80%↑ |
| AI 기반 SaaS | 60% | 70%↑ |
| IIoT (하드웨어 포함) | 40% | 60%↑ |
| 플랫폼 (마켓플레이스) | 50% | 70%↑ |

**AI 추론 비용 누락 시 → 자동 재산정 요구**

## 8. Burn Multiple (참고 지표)

### 공식

```
Burn Multiple = Net Burn ÷ Net New ARR
```

### 통과 기준

| 값 | 판정 |
|---|---|
| < 1 | 🟢 우수 (1달러 burn으로 1달러 이상 신규 ARR) |
| 1~2 | 🟢 통과 |
| 2~3 | 🟡 경고 |
| > 3 | 🔴 차단 (자본 효율성 미달) |

## 9. 보수 시나리오 스트레스 테스트

Phase 3에서 보수 시나리오 작성 시 다음 가정을 강제 적용:

- 이탈률: 가정치 × 1.5
- CAC: 가정치 × 1.3
- 신규 고객 수: 가정치 × 0.6
- 가격: 가정치 × 0.85 (할인 압박)

이 보수 시나리오에서도 LTV:CAC ≥ 2, Runway ≥ 18개월 유지 시 통과.
