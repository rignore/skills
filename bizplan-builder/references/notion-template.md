# Notion 페이지 템플릿 표준

사업계획서 Notion 페이지의 표준 구조. context.json `notion_upload: true`일 때만 적용한다 — Phase 0에서 이 템플릿으로 뼈대 페이지를 생성하고, 내용은 **각 Phase 통과 시점에만** 반영한다. 산출물의 진실의 원천은 로컬 `bizplan/{slug}/` 파일이며(SKILL.md "산출물 관리"), 작성 중·검토 중 산출물과 로그 원문은 Notion에 쓰지 않는다.

## 페이지 제목 형식

```
[사업명] 사업계획서 — [사업 유형] / [단계]
```

예시:
- `Protect GO AI 사업계획서 — AI 에이전트 / Series A`
- `K-water Yeongju Dam 사업계획서 — IIoT / Pre-seed`
- `Eureka Project 사업계획서 — 하이브리드 / Seed`

## 페이지 프로퍼티

| 프로퍼티 | 타입 | 옵션 / 값 |
|---|---|---|
| 사업명 | Title | (입력값) |
| 사업 유형 | Select | B2B SaaS / AI 에이전트 / IIoT / 하이브리드 |
| 단계 | Select | Pre-seed / Seed / Series A↑ |
| 목적 | Select | 내부 검토 / IR / 파트너십 |
| 작성자 | Person | (사용자) |
| 이해관계자 | Multi-select | CEO / CFO / CTO / 사외이사 / 리드 투자자 / ... |
| 상태 (전체) | Status | Phase 0 / Phase 1 / Phase 2 / Phase 3 / Phase 4 / 확정 / Kill Switch |
| Phase 1 상태 | Status | 작성 중 / 검토 중 / Kill Switch / 통과 |
| Phase 2 상태 | Status | 동일 |
| Phase 3 상태 | Status | 동일 |
| Phase 4 상태 | Status | 동일 |
| 마지막 수정일 | Date | (자동) |
| 작성 시작일 | Date | (자동) |

## 페이지 본문 구조

### 1) 메타 정보 블록 (페이지 최상단)

```markdown
## 📌 메타 정보

- **사업 개요**: (1-2줄 요약)
- **이해관계자**: ...
- **작성 시작일**: YYYY-MM-DD
- **목표 완료일**: YYYY-MM-DD
- **사업 유형 특이사항**: (AI 포함 시: EU AI Act 대응 필요 / IIoT 포함 시: 하드웨어 BOM 검증 필요)
```

## Notion MCP 호출 시 주의사항

- **새 페이지 생성**: `notion-create-pages` 사용, 부모 페이지는 사용자가 Phase 0 에서 지정한 페이지
- **섹션 업데이트**: `notion-update-page` 사용, 토글별로 부분 업데이트
- **변경 이력 추가**: `notion-update-page` 로 테이블 행 추가 (전체 페이지 재작성 금지)
- **상태 변경**: 페이지 프로퍼티만 업데이트, 본문 건드리지 않기

## 산출물 시각화 권장

다음 산출물은 Mermaid 또는 외부 도구로 시각화 권장:

- **Phase 1**: TAM/SAM/SOM (Pie Chart 또는 Funnel)
- **Phase 2**: 시스템 아키텍처 (Mermaid graph 또는 draw.io)
- **Phase 3**: 3개년 재무 프로젝션 (Line Chart), 단위 경제성 (Bar Chart)
- **Phase 4**: 경쟁 포지셔닝 (2x2 또는 9-Box, draw.io 권장)

Mermaid 사용 시 `Figma:generate_diagram` 도구 활용. 외부 도구 사용 시 임베드 링크를 Notion 에 삽입.

## 완성된 사업계획서 활용

Phase 4 통과 후, Notion 페이지를 다음 형식으로 변환 가능:

- **PDF 내보내기**: Notion 기본 기능 + PDF 스킬로 후처리
- **Pitch Deck (PPTX)**: One-Page Summary + Phase 1·4 핵심을 PPTX 스킬로 변환
- **Gamma 프레젠테이션**: Gamma MCP 로 자동 슬라이드 생성
- **PRD 분할**: 핵심 제품에 대해 `prd-builder` 스킬로 상세 PRD 작성
