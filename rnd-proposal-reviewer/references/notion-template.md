# Notion 페이지 템플릿

R&D 제안서 검토 리포트의 Notion 페이지 표준 구조. Phase 0에서 이 템플릿대로 빈 뼈대 페이지를 생성하고, 각 Phase 완료 시마다 해당 섹션을 채운다.

## 페이지 구조 개요

```
📄 R&D 제안서 검토 리포트 - {과제명}
├── 📊 메타 정보 (상단)
├── 🚦 Executive Summary (최상단 토글, 최종 완료 후 채움)
├── 📋 Phase 1: 행정/재무 자격 검증
├── 🔬 Phase 2: 기술 타당성 및 혁신성
├── 💼 Phase 3: 사업화 역량 및 경제성
├── 💰 Phase 4: 예산 편성 및 자원 배분
├── 🎯 Phase 5: 통합 리뷰 및 가점 전략
├── 💬 페르소나 리뷰 로그 (누적)
├── 🏆 가점 확보 체크리스트
├── ⚠️ Auto-fail 체크리스트 (최종)
└── 📝 변경 이력
```

## 생성 시 호출 도구

```
tool_search(query="notion create page")
→ Notion:notion-create-pages 로드
→ parent 파라미터에 부모 페이지 URL 또는 ID 전달
→ pages 파라미터에 제목·본문 Markdown 전달
```

## Phase별 섹션 업데이트 원칙

1. **빈 섹션 유지**: 작성 전엔 🟡 표시로 "검토 전" 명시. 빈 섹션 삭제하지 않음
2. **완료 시 상태 변경**: 🟡 → 🟢/🔴로 변경하고 세부 내용 채움
3. **페르소나 리뷰 로그는 누적**: 삭제하지 않고 시간순으로 누적
4. **변경 이력 자동 기록**: 각 Phase 완료 및 페르소나 채택 시마다 행 추가

## Notion MCP 호출 요령

### 페이지 생성

```
notion-create-pages(
  parent={부모 페이지 ID 또는 URL},
  pages=[{
    properties: { title: "R&D 제안서 검토 리포트 - {과제명}" },
    content: "{위의 전체 Markdown}"
  }]
)
```

### Phase 섹션 업데이트

Phase 완료 시 `notion-update-page`로 해당 블록만 교체. 전체 페이지 재작성 금지.

### 페르소나 리뷰 로그 추가

새 리뷰는 기존 로그 섹션에 **append** 방식으로 추가. 기존 내용 덮어쓰기 금지.

### 변경 이력 테이블 추가

Phase 진행·페르소나 채택마다 테이블에 행 추가. 기존 행 삭제 금지.

## 페이지 공유 안내

페이지 생성 후 사용자에게 다음 안내:

```
※ 페이지 공유 권한은 Notion에서 직접 설정해 주세요.
보안상 검토 시스템은 공유 권한을 자동으로 변경하지 않습니다.

이해관계자가 있다면 페이지 우측 상단 'Share' 버튼으로 권한 부여 가능합니다.
```
