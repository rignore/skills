# Auto-fail 체크리스트 마스터

Phase 1에서 자동 체크할 탈락 조건의 전체 목록. 하나라도 해당되면 기술·사업 점수와 무관하게 탈락 처리됨.

> ⚠️ 이 체크리스트는 2024~2025년 기준 정부 R&D 공통 운영 지침을 기반으로 한다. 부처·공고별로 기준이 상이할 수 있으므로 **반드시 해당 공고문을 교차 확인**한다.

## 1. 재무 건전성 (즉시 탈락)

| 항목 | 기준 | 확인 방법 | 판정 |
|---|---|---|---|
| 부채비율 | 500% 이상 | (부채총계 ÷ 자본총계) × 100 | 🔴 즉시 탈락 |
| 유동비율 | 50% 이하 | (유동자산 ÷ 유동부채) × 100 | 🔴 즉시 탈락 |
| 자본 잠식 | 자본 전액 잠식 | 자본총계 < 0 | 🔴 즉시 탈락 |
| 매출 0원 | 최근 3년 중 매출 0원 포함 | 손익계산서 | 🟡 소명 필요 |
| 연속 적자 | 최근 3년 연속 영업 적자 | 손익계산서 | 🟡 소명 필요 |

### 필요 자료
- 최근 3년 재무제표 (감사보고서 또는 표준재무제표증명원)
- 최근년도 손익계산서
- 자본변동표

### 해소 옵션
- 컨소시엄 구성: 재무 건전한 기관을 주관기관으로 전환, 해당 기업은 공동연구기관으로 참여
- 증자를 통한 부채비율·유동비율 개선
- 차년도 공고 대기

## 2. 참여 제한 (연구자·기관)

| 항목 | 기준 | 확인처 |
|---|---|---|
| 주관기관 참여 제한 | 제재 기간 중 | NTIS 통합검색 |
| 연구책임자 참여 제한 | 개인 제재 기간 중 | NTIS 연구자 정보 |
| 참여 과제 수 상한 | 부처별 상이 (통상 3건 이내) | NTIS 현황 |
| 동시 지원 금지 | 동일 목적 과제 중복 신청 | IRIS 조회 |

### 참여 과제 수 상한 (참고)
| 부처 | 연구책임자 | 참여연구원 |
|---|---|---|
| 과기정통부 | 3건 | 5건 |
| 중기부 | 3건 | 5건 |
| 산업부 | 3건 | 5건 |

## 3. 중복성 (기수행 과제 대비)

| 항목 | 기준 | 조치 |
|---|---|---|
| 기수행 과제 유사도 60% 이상 | 차별성 소명 미흡 시 | 🔴 탈락 |
| 기수행 과제 유사도 40~60% | 소명 가능 | 🟡 소명 섹션 필수 |
| 타 부처 현재 수행 중 | 중복 지원 금지 조항 위반 | 🔴 탈락 |

### 차별성 소명 방법
- 기수행 과제 목록과 본 과제의 차이점 비교표
- 기술적 진보도 (TRL 변화)
- 응용 분야 차이
- 참여 기관·연구진 차이

## 4. 행정 결격 사유

| 항목 | 기준 | 유효 기간 |
|---|---|---|
| 국세 완납 증명서 | 체납 없음 | 발급 1개월 이내 |
| 지방세 완납 증명서 | 체납 없음 | 발급 1개월 이내 |
| 4대 보험 | 체납 없음 | 최근 확인 |
| 부정당업자 제재 | 공공기관 입찰 제한 없음 | 나라장터 조회 |
| 연구윤리 위반 | 최근 5년 내 처분 없음 | NTIS 조회 |

## 5. 의무 고용 (정부 출연금 기준)

| 출연금 규모 | 청년(만 15~34세) 신규 채용 | 비고 |
|---|---|---|
| 5억 원 미만 | 자율 | 권장사항 |
| 5억 원 이상~10억 원 미만 | 1인 이상 | 인건비 편성 필수 |
| 10억 원 이상 | 출연금 5억 원당 1인 | 인건비 편성 필수 |

### 체크 포인트
- [ ] 신규 채용 인원의 인건비가 예산서에 반영되었는가
- [ ] 채용 일정이 과제 시작 3개월 이내인가
- [ ] 정규직 채용인가 (계약직은 불인정)
- [ ] 기존 직원 전환은 불가

## 6. 예산 편성 감점·탈락 조건

| 항목 | 기준 | 판정 |
|---|---|---|
| 연구책임자 참여율 | < 30% (부처 기준) | 🔴 |
| 참여 연구원 총 참여율 | > 100% | 🔴 |
| 개별 연구원 복수 과제 합산 | > 130% | 🔴 |
| 1,000만 원 이상 장비 사유서 | 누락 | 🟡 감점 |
| 위탁 연구개발비 | > 직접비의 40% | 🔴 |
| 민간 부담금 비율 | 기업 규모별 기준 미달 | 🔴 |
| 현금 매칭 비율 | 기업 규모별 기준 미달 | 🔴 |

## 7. 자격 요건 (공고별 상이)

공고문에서 반드시 확인할 항목:
- [ ] 신청 자격 (기업 유형·규모·업종·업력)
- [ ] 주관기관 자격 (중소기업만 / 중견 포함 / 대학 주관 여부)
- [ ] 컨소시엄 구성 의무 (수요기업 참여 필수 여부)
- [ ] 특정 기술 분야 제한
- [ ] 지역 제한 (수도권 제외·지방 가점 등)

## 8. 보안·윤리 결격

| 항목 | 기준 |
|---|---|
| 연구윤리 위반 이력 | 최근 5년 내 |
| 논문 표절·중복 게재 | 확인 시 탈락 |
| 연구비 부정 사용 이력 | 최근 5년 내 |
| 개인정보 유출 사고 | 최근 3년 내 |

## 체크리스트 실행 절차

1. 사용자로부터 재무제표·참여자 정보·기수행 과제·완납 증명 자료 입수
2. 위 7개 카테고리를 순차 적용하여 🟢/🟡/🔴 판정
3. 🔴 발견 시 즉시 사용자에게 고지 및 해소 옵션 제시
4. 모든 카테고리 🟢 또는 🟡(소명 완료) 상태일 때만 Phase 2 진입 승인
5. Notion 리포트의 "Auto-fail 체크리스트" 섹션에 최종 결과 기록

## 최종 Notion 기록 포맷

```markdown
## ⚠️ Auto-fail 체크리스트 (최종)

| # | 카테고리 | 판정 | 세부 사항 |
|---|---|---|---|
| 1 | 재무 건전성 | 🟢 | 부채비율 180%, 유동비율 120% |
| 2 | 참여 제한 | 🟢 | 전원 이상 없음 |
| 3 | 중복성 | 🟡 | 기수행 과제 유사도 42% → 차별성 소명 포함 |
| 4 | 행정 결격 | 🟢 | 완납 증명 유효 |
| 5 | 의무 고용 | 🟢 | 청년 2인 신규 채용 인건비 반영 |
| 6 | 예산 편성 | 🟢 | Phase 4 완료 후 확정 |
| 7 | 자격 요건 | 🟢 | 공고 자격 부합 |
| 8 | 보안·윤리 | 🟢 | 결격 없음 |

**종합 판정**: 🟢 통과 → Phase 2 진입 가능
```
