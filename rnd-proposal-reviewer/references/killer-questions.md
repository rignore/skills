# 킬러 질문 마스터 뱅크

페르소나별 킬러 질문의 전체 목록. 각 Phase 리뷰 시 이 뱅크에서 과제 특성에 맞는 질문을 선별하여 사용한다.

## 사용 원칙

1. **선별 사용**: 한 페르소나당 2~3개 질문만 선별. 전체 나열은 금물
2. **제안서 미답변 우선**: 제안서에 이미 답이 있는 질문은 제외, 답이 없거나 약한 질문 우선
3. **도메인 맞춤**: 도메인과 무관한 질문은 제외
4. **실제 평가위원 재현**: 단순 확인 질문이 아니라 "어떻게 보장할 것인가?", "실패 시 대안은?" 같은 심층 질문 위주

## 1. AI 알고리즘 페르소나

### 데이터
- 학습 데이터의 라벨 품질은 어떻게 검증했는가? Inter-annotator agreement는 몇 %인가?
- Train/Test 분할 시 시간적·공간적 데이터 누수(leakage)는 없는가?
- 데이터 라이선스·저작권·개인정보 처리의 적법성은 어떻게 확보했는가?
- 실제 운영 환경의 데이터 분포가 학습 데이터와 얼마나 다른가? 분포 이동 대응은?

### 모델
- 베이스라인 대비 제안 모델의 성능 향상이 통계적으로 유의한가 (p-value)?
- 경량화(Quantization, Pruning, Distillation) 전후 성능 변화는?
- 파라미터 수·FLOPs·메모리 요구가 타겟 디바이스 사양에 부합하는가?

### 강건성·편향
- 본 AI 에이전트가 처리하는 비정형 데이터의 노이즈 비율이 20% 이상인 현장 환경에서 모델의 강건성(Robustness)을 보장하기 위한 구체적인 데이터 증강 또는 필터링 기법은?
- 적대적 입력(Adversarial Attack)에 대한 방어 메커니즘은?
- 학습 데이터의 편향을 어떻게 검증·보정하는가? 공정성 지표는 무엇인가?

### LLM·생성형 AI
- 할루시네이션 발생 시 탐지·차단·후처리 로직은 무엇인가?
- RAG 사용 시 검색 품질(Precision@K)은 어떻게 측정하는가?
- 프롬프트 인젝션 대비 방어 체계는 어느 수준인가?
- 토큰 비용·레이턴시·운영비가 사업성을 무너뜨리지 않는가?

### 측정·평가
- KPI 측정 시 공인 시험기관(TTA 등)의 재현 가능한 프로토콜이 마련되었는가?
- Accuracy뿐 아니라 Precision/Recall/F1 등 종합 지표를 제시했는가?
- 부정적 KPI(오탐률, 지연시간 등)도 측정·공개하는가?

## 2. SW 아키텍처 페르소나

### CSAP
- 공공 클라우드 환경에서 타 서비스와의 물리적/논리적 분리를 위해 CSAP 31개 통제 항목 중 '가상화 보안'과 '접근 통제'를 어떠한 기술적 방식으로 구현할 예정인가?
- CSAP 인증 획득 일정이 과제 종료일 이전인가? 인증 지연 시 Plan B는?
- CSAP 전용 인프라 구축 비용이 예산에 반영되었는가?

### MSA·확장성
- 서비스 간 통신 장애 시 Circuit Breaker·Retry·Timeout 정책은 어떻게 구성되는가?
- 트래픽 10배 증가 시 수평 확장 가능한 병목 지점은 어디인가?
- 단일 장애점(SPOF)이 있는가? 어떻게 제거하는가?

### 멀티테넌시
- 동일 DB 내 타 테넌트의 데이터에 접근하는 SQL 인젝션 시나리오 방어 체계는?
- 테넌트별 암호화 키 분리 여부와 키 관리 방식은?
- 관리자 계정 탈취 시 Blast Radius는 어디까지인가?

### 무중단·복구
- 배포 실패 시 Rollback 소요 시간은 몇 분인가?
- 데이터센터 전체 장애 시 RTO/RPO 달성 가능한가?
- 장애 복구 시나리오에 대한 정기 모의 훈련 계획은?

### 관측성·운영
- 로그·메트릭·트레이싱 3요소가 모두 수집되는가?
- SLI/SLO 정의와 오류 예산(Error Budget) 운영 방침은?
- 온콜(On-call) 체계와 평균 장애 탐지·복구 시간(MTTD/MTTR) 목표는?

## 3. IoT/에지 페르소나

- LoRa/Zigbee/5G 중 선정 근거를 대역폭·레이턴시·전력·커버리지·비용 4축으로 설명할 수 있는가?
- 통신 단절 시 로컬 버퍼링 용량과 데이터 우선순위 정책은?

### 국산화
- 하드웨어 국산화율 목표와 달성 불가 시 대체재 확보 경로는?
- 핵심 부품(MCU, 이미지 센서 등)이 특정 국가 수출 규제에 영향받지 않는가?
- 조립·검사의 국내 수행 비율은?

### 에지 AI
- 에지 디바이스의 NPU 사양이 제안 모델 추론에 충분한가?
- 모델 업데이트 시 전체 디바이스 OTA 배포 방식과 실패 디바이스 비율 허용 기준은?
- 에지 추론 레이턴시 목표와 실측 값의 차이는?

### 보안
- 디바이스 인증·프로비저닝 방식은 안전한가 (초기 키 분배 보안)?
- 펌웨어 서명·OTA 업데이트 무결성 검증 체계는?
- 에지 ↔ 클라우드 통신 암호화 방식은?

## 4. 스마트 제조 페르소나

### KPI 현실성
- 목표로 제시한 '공정 불량률 15% 감소'가 도입 기업의 현재 설비 성능(Capa)과 원재료 수급 변동성을 고려할 때, 제안 기술만으로 달성 가능한 수치인가?
- 생산성 향상이 AI 도입의 직접 효과인가, 프로세스 재설계 효과인가? 분해 측정 가능한가?
- KPI 측정 기간 중 계절성·발주 변동·작업자 교체 변수 통제 방법은?

### 레거시 연동
- 기존 ERP/MES/SCADA 시스템과의 연동 방식이 명시되었는가?
- 데이터 사일로 발생 위험 대응책은?
- 현장 PLC 신호 수집 시 OPC-UA 표준 지원 설비 비율과 비지원 설비 대응책은?

### 현장 수용성
- 현장 실무자가 직접 데이터를 분석할 수 있는 대시보드 및 시각화 도구의 제공 여부는?
- 모바일 알림·한국어 UI·현장 용어 반영 계획은?
- 도입 후 6개월 시점 사용률 목표와 미달 시 대응 방안은?

### 확산성
- 타겟 수요 기업의 공정 특성이 타 업종·타 공장으로 확산 가능한 일반성을 갖추었는가?
- 솔루션이 구축형인지 SaaS 전환 경로인지, 확산 단가 경쟁력은?
- 중소기업 수요처 대상 도입 비용이 정부 지원 기준 이내인가?

## 5. 에너지 계통 페르소나

### 계통 안정성
- 제안된 신재생 에너지 예측 알고리즘이 기상 이변으로 인한 간헐성(Intermittency)을 제어하지 못해 전력 계통에 과부하를 줄 경우, 이를 차단하거나 ESS로 즉각 우회시키는 보호 협조 체계가 설계되어 있는가?
- 한전 계통 연계 기준(배전선로 용량·전압·주파수)을 만족하는 실증 계획과 연계 심의 일정은?
- 역조류(Reverse Power Flow) 발생 시 보호 계전기 동작 연동 방식은?

### 예측
- 발전량 예측 MAPE 목표가 현재 국내외 SOTA 대비 어느 수준인가?
- 기상 정보 API 장애 시 대체 입력·안전 예측 로직은?
- 예측 실패로 인한 정산 손실 발생 시 책임 분담 구조는?

### ESS·VPP
- ESS 충방전 최적화 알고리즘이 배터리 수명(Cycle Life)을 고려하는가?
- VPP 구성 자원의 통신 단절 시 운영 지속성은?
- 전력 시장 입찰 전략이 시장 규칙 변화에 robust한가?

### 탄소 저감
- 탄소 배출 저감 효과 산출이 LCA 기반인가, 단순 발전량 × 배출계수인가?
- 제안 기술의 생산·설치·폐기 단계 배출량도 고려했는가?
- CDM·K-ETS 연계 가능성 검토했는가?

### 규제
- 수소 충전소 인근 시설 제한, 이격 거리 등 현행 규제가 사업화에 걸림돌이 되지 않는가?
- 규제 샌드박스 신청 필요성이 있다면 일정은?

## 6. DX/비즈니스 페르소나

### 경쟁·차별화
- 본 서비스가 타겟으로 하는 시장에 이미 글로벌 독점 기업(Microsoft, Salesforce 등)이 존재하는데, 이들과의 가격 경쟁이나 기능적 차별화 없이 어떻게 고객 전환 비용(Switching Cost)을 극복할 것인가?
- 경쟁사 대비 결정적 Wedge(진입 쐐기)는 무엇인가?
- 국산 솔루션으로서의 포지셔닝이 공공·규제 산업에서 실제 구매 결정 요인인가?

### 단위 경제성
- B2B SaaS의 핵심은 낮은 이탈률(Churn rate)과 높은 CLTV/CAC 비율이다. 구독형 모델로의 전환에 따른 연도별 수익 추정치를 어떻게 설계했는가?
- CAC Payback이 18개월을 초과하면 자본 효율성이 무너진다 — 현재 가정 하의 Payback은?
- NRR 110% 달성을 위한 업셀·크로스셀 경로가 구체적으로 설계되었는가?

### 수요 기업 확약
- 첨부된 구매 확약서의 실제 구매 의사 수준은? (MOU / LOI / 조건부 구매 / 확정 PO)
- 수요 기업이 단일 대기업에 쏠려 있지 않은가? 복수 업종 확산 가능성은?
- 과제 종료 후에도 지속 구매할 락인(lock-in) 요인은?

### 글로벌
- 내수 시장만으로 3년 후 TAM을 달성 가능한가?
- 글로벌 SaaS로 가기 위한 인증·규정 준수(GDPR, SOC 2) 로드맵은?
- 해외 파트너·총판과의 협력 계획이 MOU 수준 이상인가?

### 시장 규모
- TAM·SAM·SOM 산출이 Top-down과 Bottom-up 교차 검증되었는가?
- 시장 성장률(CAGR) 출처의 신뢰도는? (Gartner·IDC 등 공인 리서치 여부)
- SOM 달성 시 매출 목표가 실제 영업 역량·채널·가격과 정합하는가?

### 영상·개인정보

- 영상 데이터가 해외 클라우드로 전송될 경우 국외이전 절차를 준수하는가?

### 증거력·로그 무결성
- 사고 로그의 위변조 여부를 법정에서 증명할 수 있는 기술적 근거는?
- 타임스탬프가 공인 시각 인증(TSA)에 연동되는가?

### 보안 인증

- 취약점 점검·모의 해킹 정기 일정과 외부 위탁 기관은?

- 실증 특례 기간 종료 후 법제화 경로는 마련되었는가?

## 8. 전력설비 전기공학 페르소나 (도메인 특화)

### 부분방전·UHF 센싱
- UHF 센서가 감지하는 주파수 대역에 외부 무선 통신·방송 신호 노이즈가 포함될 때, 실제 PD 신호와 구분하는 알고리즘과 오검출률(False Alarm Rate) 목표는?
- 배전반 내부의 전자기 차폐 구조로 인한 UHF 신호 감쇠 문제는 어떻게 해결하며, 센서 설치 위치 최적화 근거는?
- PD 패턴 분류(코로나·표면·내부·플로팅) 성능을 입증할 학습 데이터 규모와 현장 PD 데이터 확보 경로는?
