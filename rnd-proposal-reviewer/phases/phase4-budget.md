# Phase 4 — 예산 편성 및 자원 배분 리뷰 (Budget Workflow)

가장 빈번하게 감점이 발생하는 구간. 연구비 편성 지침 준수 여부를 정량으로 검토한다.

## 목표

- 연구비 편성 지침 위반 항목 사전 차단
- 인건비·간접비·현금 매칭 비율의 정확성 확인
- 장비·재료비 등 1,000만 원 이상 항목의 사유서 첨부 확인
- 예산 배분이 마일스톤과 정합하는지 검증

## 주도 페르소나

- **안전/보안 규제** (체크리스트 주관)
- **DX/비즈니스** (예산-수익 모델 정합성)

## 검토 프레임워크

### 1. 인건비 및 참여율

- [ ] **연구책임자 최소 참여율**: 부처별 기준(통상 30% 이상) 준수
- [ ] **참여 연구원 총 참여율 합계**: 100% 이내 (초과 시 감점)
- [ ] 개별 연구원의 복수 과제 참여 합산이 130% 이내
- [ ] 신규 채용 예정 인원의 인건비 편성 (청년 고용 의무 연계)
- [ ] 인건비 단가가 정부 기준 노임 단가 범위 이내

**부처별 참여율 기준 참고**
| 부처 | 연구책임자 최소 참여율 |
|---|---|
| 과기정통부 | 30% |
| 중기부 | 30% |
| 산업부 | 30% |
| 기업부설연구소 소속 | 20% (일부 완화) |

### 2. 직접비 세부 항목

#### 연구장비·재료비
- [ ] **1,000만 원 이상 연구 장비** 도입 시 사유서 첨부 여부
- [ ] 장비의 과제 종료 후 활용 계획 명시
- [ ] 기존 보유 장비와의 중복 여부 소명
- [ ] 재료비는 소비성 재료로 한정 (자산성은 불가)

#### 연구활동비
- [ ] 회의비·국내외 출장비·수용비 등 세부 항목별 편성 근거
- [ ] 출장비 단가가 공무원 여비 규정 기준 이내

#### 연구개발비
- [ ] 외주 용역비 편성 시 과업 내용·금액 근거 명시
- [ ] 위탁 연구개발비가 전체 직접비의 40% 이내

### 3. 간접비

- [ ] 부처·기관별 **간접비 계상 비율** 준수
- [ ] 간접비 고시율이 있는 경우 해당 비율 적용
- [ ] 간접비 용도 (기관 운영·인건비 가산·행정 지원) 구분 명시

**기관 유형별 간접비 고시율 참고 (2024년 기준)**
| 기관 유형 | 간접비율 |
|---|---|
| 대학교 | 17~25% |
| 정부출연연구기관 | 고시율 적용 |
| 기업 (중소) | 5~17% |
| 기업 (중견·대기업) | 5~10% |

### 4. 현금·현물 매칭 (민간 부담금)

- [ ] 기업 규모별 **민간 부담금 비율** 준수
- [ ] 민간 부담금 중 **현금 납입 비율** 준수 (통상 10~15% 이상)
- [ ] 현물은 인건비·기존 자산 활용 등으로 객관 산정
- [ ] 컨소시엄 구성 시 기관별 부담 비율 합산 확인

**기업 규모별 민간 부담금 비율 (일반 기준)**
| 기업 규모 | 민간 부담금 | 현금 비율 (민간 부담금 중) |
|---|---|---|
| 중소기업 | 25% 이상 | 10% 이상 |
| 중견기업 | 30~40% | 13% 이상 |
| 대기업 | 50% 이상 | 15% 이상 |

### 5. 마일스톤-예산 정합성

- [ ] 연차별 예산 배분이 마일스톤 난이도와 정합하는가
- [ ] 1년차에 장비·셋업 비중 집중, 2~3년차에 실증 비중 증가가 자연스러운가
- [ ] 특정 연차에 이상 집중(예: 3년차에 전체의 70%)이 있다면 사유 명시

## 자주 발견되는 감점 포인트

1. **연구책임자 참여율 부족**: 29%처럼 기준(30%) 바로 아래
2. **참여율 합계 초과**: 101%, 102% 등 소수점 관리 실패
3. **장비 사유서 누락**: 1,100만 원 서버 구매에 사유서 없음
4. **현금 매칭 비율 부족**: 중소기업인데 현금 8%만 편성
5. **위탁 연구개발비 과다**: 전체 직접비의 50% 등
6. **신규 청년 채용 인건비 누락**: 출연금 10억 원인데 청년 채용 인건비 0

## 진행 절차

1. 제안서의 예산 편성표를 입력받아 파싱
2. 위 체크리스트를 순차 적용하여 🟢/🟡/🔴 판정
3. 🔴 발견 시 수정 권고안 함께 제시
4. 최종 예산안 확정 후 Phase 5 진입

## 🔴 차단 이슈 기준

- 연구책임자 참여율 < 부처 기준
- 참여 연구원 총 참여율 > 100%
- 현금 매칭 비율 < 기업 규모별 기준
- 1,000만 원 이상 장비 사유서 누락
- 위탁 연구개발비 > 40%
