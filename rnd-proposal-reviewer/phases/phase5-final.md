# Phase 5 — 통합 리뷰 및 가점 전략

Phase 1~4를 통과한 제안서에 대해 7인 페르소나가 종합 관점에서 한 번 더 점검하고, 고득점을 위한 가점 전략을 적용한다.

## 목표

- Phase 1~4의 결함이 모두 보완되었는지 최종 확인
- 가점 항목 체크리스트 적용
- 평가위원 관점의 Executive Summary 작성
- 제출 직전 최종 Go/No-Go 판단

## 주도 페르소나

**전원 종합 리뷰**. 단, 도메인별 1차 페르소나가 주도하고 나머지는 보조.

## 최종 통합 체크리스트

### 1. 논리적 일관성

제안서 전반에 걸쳐 아래 흐름이 일관되는지 확인:

```
문제 정의 → 기술 혁신성 → 해결 방식 → KPI → 수요처 → 시장 → 사업화 → 정책 기여
```

- [ ] Phase 1에 명시된 문제가 Phase 3의 시장 규모와 정합하는가
- [ ] Phase 2의 KPI가 Phase 3의 수익 모델 가정(예: 정확도가 높을수록 고객 단가 상승)과 연결되는가
- [ ] Phase 4의 예산이 Phase 2의 마일스톤을 뒷받침하는가
- [ ] 수요처의 요구사항이 기술 개발 목표에 반영되었는가

### 2. 가점 확보 전략

정부 R&D 제안서 가점에 결정적인 항목들.

#### 공인 인증 로드맵
- [ ] **TTA(한국정보통신기술협회) V&V 시험** 획득 계획 (SW 품질)
- [ ] **GS인증**(Good Software) 획득 계획
- [ ] **CSAP 인증** (클라우드 서비스) 등급 및 일정
- [ ] **KC인증**(하드웨어) 또는 KOLAS 시험성적서
- [ ] **국제 인증** (CE, FCC, UL, ISO 27001 등)

#### 특허 로드맵 (Patent Map)
- [ ] 원천 기술 특허 출원 계획 (국내 + PCT)
- [ ] 개량 기술 특허 포트폴리오
- [ ] 경쟁사 특허 회피 설계 분석
- [ ] 특허 등록 목표 수 + 사업 기간 내 확보 전략

#### 수요처 참여 강도
- [ ] 단순 구매 확약 → 공동 개발 참여 수준으로 격상
- [ ] 테스트베드 제공 (현장 데이터·인프라)
- [ ] 과제 종료 후 3년간 레퍼런스 활용 동의
- [ ] 복수 수요처(대기업·중견·중소 혼합)

#### 사회적 가치 연결
| 정부 정책 테마 | 연결 방식 |
|---|---|
| 탄소 중립·2050 NetZero | 탄소 저감 효과(t-CO₂/년) 산출 |
| 중대재해 예방 | 중대재해법 대응 체계 강화 |
| 디지털 전환 | 중소기업 디지털 역량 확산 |
| 국산화·공급망 안정화 | 외산 대체율·수입 대체 효과 |
| 청년 고용 | 청년 신규 채용 N명·정규직 전환 |
| 지역 균형 | 비수도권 기업 참여·지역 고용 |

#### 글로벌 진출 근거
- [ ] 해외 파트너사 MOU 첨부
- [ ] 글로벌 표준(W3C, IEC, IEEE 등) 참여
- [ ] 해외 실증 사이트 확보 계획

### 3. 평가 배점 시뮬레이션

도메인·부처별 배점에 맞춰 현재 제안서의 예상 점수 산출.

**예: IITP 일반 과제 배점 참고**
| 항목 | 배점 | 현재 예상 |
|---|---|---|
| 기술성 | 40 | {N}/40 |
| 사업성 | 30 | {N}/30 |
| 수행 역량 | 20 | {N}/20 |
| 정책 부합성 | 10 | {N}/10 |
| **합계** | **100** | **{N}/100** |

> 공고별 실제 배점은 다르므로 공고문 확인 필수.

### 4. 7인 페르소나 최종 코멘트

각 페르소나가 한 줄 코멘트로 최종 판단:

```
[AI 알고리즘] 🟢 모델 혁신성 명확, 학습 데이터 확보 경로 추가 권장
[SW 아키텍처] 🟡 CSAP 하등급 대응 계획 보완 필요
[IoT/에지] 🟢 국산화율 목표·통신 프로토콜 근거 탄탄
[스마트 제조] 🟢 수요처와 현장 실증 계획 명확
[에너지 계통] - (해당 없음)
[DX/비즈니스] 🟢 CLTV/CAC 3.2:1, 구매 확약 3곳
[안전/보안 규제] 🟡 영상 비식별화 기술 명세 보강 필요
```

### 5. 최종 Go/No-Go 판정

**Go 조건 (모두 충족)**:
- Phase 1~4 모두 🟢 또는 보완 완료
- 가점 항목 중 최소 3개 이상 확보
- 7인 페르소나 중 🔴 없음

**No-Go / 제출 연기 권고**:
- Phase 1 🔴 미해소
- 수요처 확약 전무 + Phase 3 차단
- 예산 지침 위반 다수

## 진행 절차

1. Phase 1~4 결과를 전체 요약표로 집계
2. 가점 체크리스트 적용
3. 7인 페르소나 각각에게 최종 한 줄 코멘트 요청
4. Executive Summary 작성 (제안서 첫 페이지에 삽입 가능한 수준)
5. Go/No-Go 판정 및 최종 Action Item 리스트 제시

## 산출물: Executive Summary 템플릿

제안서 맨 앞에 붙일 수 있는 수준의 요약. 평가위원이 5분 안에 핵심을 파악할 수 있도록 구성.

```markdown
# {과제명} Executive Summary

## 🎯 한 문장 요약
{과제가 해결하는 문제·기술·수요처·성과 한 문장}

## 💡 기술 혁신성
- Global SOTA 대비 {차별점}
- 핵심 KPI: {정량 목표 3개}
- 공인 인증 로드맵: {TTA/GS/CSAP 등}

## 💼 사업화 경로
- 수요처: {확약 기업 N곳, 총 도입 규모}
- 시장 규모: SOM {금액} (5년 후)
- 수익 모델: {구독형/도입형 + 단위 경제성}

## 🌍 정책 기여
- {사회적 가치 1}: {정량 효과}
- {사회적 가치 2}: {정량 효과}

## 👥 수행 역량
- 연구책임자·핵심 연구원 {N명}
- 컨소시엄: {기관 구성}
- 기존 유사 과제 성공 실적: {N건}

## 💰 예산 및 일정
- 총 사업비: {금액} / 정부 출연금: {금액}
- 기간: {N}개월 / 마일스톤 {N}개
```
