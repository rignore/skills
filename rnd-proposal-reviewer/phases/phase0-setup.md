# Phase 0 — 세팅

제안서 검토를 시작하기 전 반드시 거치는 단계. 과제 맥락·모드·도메인을 확정하고 Notion 검토 리포트 뼈대 페이지를 만든다.

## 목표

- 검토 모드(Review/Build)와 도메인 확정
- 발주 기관의 평가 관성 파악
- Notion에 빈 토글이 있는 검토 리포트 뼈대 생성
- Phase 1(행정/재무 자격 검증) 진입 준비

## 사용자에게 묻는 질문 (한 번에)

```
정부 R&D 제안서 검토를 시작하겠습니다. 시작 전에 다음 7가지를 알려주세요.

1. **모드 선택**:
   - **Review**: 이미 작성된 제안서를 검토
   - **Build**: 제로베이스에서 제안서 기획 (7인 전문가가 질문으로 가이드)

2. **과제명 및 발주 기관**: 
   예) "2026 스마트 제조혁신 지원사업 / 중기부·스마트제조혁신추진단"
   예) "IITP 차세대 AI 반도체 R&D / 과기정통부"

3. **사업 공고 URL**: IRIS 공고 페이지 링크 (있으면)

4. **도메인 (복수 선택 가능)**:
   - 신재생 에너지 / 에너지 계통
   - 스마트 팩토리 / 지능형 제조
   - AI 에이전트 / LLM 기반 서비스
   - B2B SaaS / 클라우드 전환
   - AIoT 기반 산업 안전
   - 전력설비 화재·절연열화 진단 (배전반·ESS·태양광)
   - 기타 (직접 입력)

5. **Notion 부모 페이지**: 검토 리포트를 어디에 만들까요? (URL 또는 페이지명)

6. **제안서 자료** (Review 모드): PDF/Notion 페이지/텍스트 붙여넣기

7. **마감일**: 제출 마감까지 남은 시간 (긴급도에 따라 검토 깊이 조정)
```

## 사용자 답변 처리

### 모드별 처리

**Review 모드**
- Phase 1~5 순차 진행하며 결함 탐지
- 제안서 자료가 필수. 없으면 Build 모드 제안

**Build 모드**
- Phase 1(자격)부터 시작하되, 제안서가 아직 없으므로 각 Phase의 "킬러 질문"을 역으로 활용하여 기획 가이드
- Phase마다 사용자 답변을 받아 제안서 초안을 Notion에 누적

### 도메인별 페르소나 우선순위 자동 설정

| 도메인 | 1차 호출 페르소나 | 2차 호출 페르소나 |
|---|---|---|
| 신재생 에너지 | 에너지 계통, IoT/에지 | SW 아키텍처, 안전/보안 |
| 스마트 팩토리 | 스마트 제조, IoT/에지 | AI 알고리즘, 안전/보안 |
| AI 에이전트 | AI 알고리즘, SW 아키텍처 | DX/비즈니스, 안전/보안 |
| B2B SaaS | SW 아키텍처, DX/비즈니스 | AI 알고리즘, 안전/보안 |
| AIoT 안전 | 안전/보안, IoT/에지 | AI 알고리즘, SW 아키텍처 |
| 전력설비 화재·진단 | 전력설비 전기공학, IoT/에지 | 안전/보안, AI 알고리즘, 에너지 계통 |

### 발주 기관별 평가 관성 반영

| 기관 | 강조 포인트 | 감점 포인트 |
|---|---|---|
| IITP | 기술 혁신성, Global SOTA 비교, 원천 기술 | 상용화 로드맵 약함 |
| NIPA | 사업화·수출·실증·글로벌 | 기술 혁신성만 주장 |
| 중기부·스마트제조혁신추진단 | 수요기업 참여, 고용, 현장 KPI | 대기업 성격 과제 |
| 산업부 | 공정/에너지 KPI, 탄소 저감 | 사회적 가치 누락 |
| 지자체 | 지역 기반, 지역 고용 | 타지역 확산성 부족 |

## 뼈대 페이지 생성

`references/notion-template.md`의 구조를 따라 Notion 페이지를 생성한다.

### 단계

1. `tool_search` 호출하여 Notion MCP 도구(`notion-create-pages`) 로드
2. 부모 페이지 식별 (URL 또는 notion-search로 검색)
3. `notion-create-pages`로 페이지 생성
4. 생성된 페이지 URL을 사용자에게 전달

### 페이지 본문 표준 구조

```markdown
# R&D 제안서 검토 리포트 - {과제명}

> 검토 일자: {오늘 날짜}
> 모드: {Review | Build}
> 발주 기관: {기관명}
> 공고 URL: {URL}
> 도메인: {도메인 목록}
> 마감일: {D-N일}
> 검토자: {PM명}

---
```
