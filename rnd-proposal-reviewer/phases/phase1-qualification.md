# Phase 1 — 행정/재무 자격 검증 (Qualification Workflow)

평가 시작 전 'Auto-fail' 조건을 차단하는 단계. 2024~2025년 기준 정부 R&D 공통 운영 지침에 따른 엄격한 재무·행정 지표를 자동 체크한다.

## 목표

- 재무 건전성 Auto-fail 조건 확인
- 참여 제한·중복성 리스크 사전 차단
- 의무 고용·세금 체납 등 행정 결격 사유 점검
- **단 하나라도 🔴가 발견되면 Phase 2 진입 금지**

## 주도 페르소나

- **안전/보안 규제** — 법적 결격 사유·세금 체납·고용 의무 체크리스트 주관
- 그 외 페르소나는 해당 사항 없음 (자격 단계)

## 체크리스트

### 1. 재무 건전성 (Auto-fail)

최근 3년 재무제표를 파싱하여 실시간 산출. 하나라도 해당되면 🔴.

| 항목 | 기준 | 확인 방법 |
|---|---|---|
| 부채비율 | 500% 이상 → 🔴 | (부채총계 ÷ 자본총계) × 100 |
| 유동비율 | 50% 이하 → 🔴 | (유동자산 ÷ 유동부채) × 100 |
| 자본 잠식 | 자본 전액 잠식 → 🔴 즉시 탈락 | 자본총계 부호 확인 |
| 영업이익 | 최근 3년 연속 적자 → 🟡 추가 소명 필요 | 손익계산서 확인 |

### 2. 참여 제한 및 연구자 결격

- [ ] NTIS 연구자 정보 내 주관기관의 '참여 제한' 내역 유무
- [ ] 연구책임자 개인의 '참여 제한' 내역 유무
- [ ] 연구책임자의 당해연도 참여 과제 수 (부처별 상한 확인)
- [ ] 공동연구기관의 참여 제한 유무

### 3. 중복성 (기수행 과제 대비 차별성)

- [ ] NTIS 검색을 통해 최근 3년간 지원받은 유사 과제 목록 확인
- [ ] 기수행 과제와의 유사도 **60% 이상** → 차별성 소명 필수
- [ ] 타 부처 현재 수행 중 과제와의 중복 여부

### 4. 행정 결격 사유

- [ ] 국세 완납 증명서 유효 기간 (통상 1개월 이내 발급분)
- [ ] 지방세 완납 증명서 유효 기간
- [ ] 4대 보험 체납 여부
- [ ] 공공기관 부정당업자 제재 여부

### 5. 의무 고용 (해당 시)

정부 출연금 규모별 청년 신규 채용 의무.

| 출연금 규모 | 의무 채용 |
|---|---|
| 5억 원당 | 청년(만 15~34세) 1인 신규 채용 |
| 10억 원 초과 | 2인 이상 권장 |

- [ ] 인건비 항목에 신규 채용 예정 인원의 인건비 편성 확인
- [ ] 채용 일정이 과제 시작 3개월 이내인지 확인

## 사용자 입력 받기

```
Phase 1을 시작합니다. 다음 자료를 공유해 주세요.

1. **최근 3년 재무제표** (또는 주요 지표만):
   - 자본총계, 부채총계, 유동자산, 유동부채
   - 매출액, 영업이익 (3년치)

2. **참여 연구자 정보**:
   - 연구책임자 소속·직위, NTIS 등록 여부
   - 현재 수행 중인 다른 정부 과제 목록 (있다면)

3. **기수행 과제**: 최근 3년간 정부 지원받은 과제 제목·부처·과제번호

4. **완납 증명**: 국세/지방세 완납 증명서 발급 일자

5. **출연금 규모**: 신청 예정 정부 출연금 (억 원)
```

## Auto-fail 감지 시 대응

🔴 차단 이슈 발견 시 다음 메시지를 사용자에게 전달:

```
⚠️ Auto-fail 조건이 감지되었습니다.

발견된 이슈:
- {항목}: {현재 값} (기준: {기준 값})

이대로 제안서를 제출할 경우 기술·사업 점수와 무관하게 **탈락** 처리됩니다.

대응 옵션:
1. **이슈 해소 후 제출**: {구체적 해소 방법}
2. **컨소시엄 구성**: 재무 결격의 경우 건전한 주관기관을 공동연구기관으로 전환
3. **차년도 공고 대기**: 해소에 시간이 필요하면 차년도 공고 기다리기

어떻게 진행하시겠어요?
```

## 통과 기준

- 재무 4개 항목 모두 기준 이내
- 참여 제한·중복성 모두 🟢
- 행정 결격 없음
- 의무 고용 인건비 편성 완료

모두 통과 시 Phase 2 진입 가능.

## 페르소나 호출

Phase 1은 객관적 체크리스트 성격이 강하므로 페르소나 호출은 선택사항. 단, 🔴 차단 이슈 발생 시 **안전/보안 규제** 페르소나를 호출하여 대응 전략 질의.
