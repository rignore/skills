# Phase 3 — 사업화 역량 및 경제성 리뷰 (Business Workflow)

비즈니스 및 규제 전문가가 주도하여 '수익 창출'과 '고용 확대'라는 정부의 정책적 목적 달성 여부를 평가한다. 제안서가 "개발비 수령"에 그치지 않고 "과제 종료 후 자생"하는 경로를 갖추었는지 검증.

## 목표

- 수요 기업 확약의 신뢰도 확인
- 수익 모델의 경제성 검증 (CLTV/CAC, 단위 경제성)
- 글로벌 진출 가능성과 국내외 경쟁 구도 분석
- 정부 정책 테마와의 연결 강도 평가

## 주도 페르소나

- **DX/비즈니스** (주도) — TAM/SAM/SOM, 수익 모델, 시장 경쟁
- **스마트 제조** — 수요 기업 참여·현장 KPI (제조 도메인일 때)
- **에너지 계통** — 탄소 저감 효과의 경제 가치 (에너지 도메인일 때)
- **안전/보안 규제** — 규제 대응을 사업 기회로 전환 (안전 도메인일 때)

## 검토 프레임워크

### 1. 수요 기업 확약 (가장 결정적)

- [ ] **구매 확약서**(LOI 이상 수준) 또는 **실증 의향서**가 첨부되었는가
- [ ] 수요 기업의 규모(매출·종업원 수)가 성과 확산에 적합한가
- [ ] 단일 기업이 아닌 **복수 수요처**인가 (쏠림 리스크 차단)
- [ ] 수요 기업이 개발 단계부터 참여하여 테스트 베드를 제공하는가
- [ ] 확약 금액·도입 일정이 구체적으로 명시되었는가

**탐지 예시**
- 🔴 수요 기업 없음, 또는 "협의 중"이라는 모호한 표현
- 🟡 단일 수요 기업, 규모 작음 (중소기업 1개만)
- 🟢 복수 대기업·중견기업의 구매 확약서, 각각 도입 규모 명시

### 2. 시장 규모 (TAM/SAM/SOM)

- [ ] TAM(총 시장)·SAM(유효 시장)·SOM(획득 가능 시장)이 각각 제시되었는가
- [ ] 시장 규모 산출 근거(Top-down + Bottom-up 교차 검증)가 명확한가
- [ ] 국내 시장 vs 글로벌 시장이 구분되었는가
- [ ] 과제 종료 5년 후 SOM 달성 시 매출 목표가 현실적인가

### 3. 수익 모델 (Revenue Model)

도메인별 핵심 체크:

**B2B SaaS**
- [ ] 구독형(시트당 / 사용량 기반 / 하이브리드) 가격 정책
- [ ] Churn rate 목표 (업계 평균 5~10%)
- [ ] CLTV/CAC 비율 목표 (3:1 이상 권장)
- [ ] CAC Payback 기간 (12~18개월 이하)
- [ ] NRR(Net Revenue Retention) 목표 (110% 이상)

**스마트 팩토리 / 제조 AI**
- [ ] 구축형 vs SaaS 비중 전략
- [ ] 초기 도입 비용 vs 월 운영비 구조
- [ ] 유지보수·업데이트 수익 구조

**신재생 에너지**
- [ ] 발전 사업자 대상 PPA / 구독형 최적화 서비스 모델
- [ ] 탄소 크레딧 거래 수익 포함 여부
- [ ] 한전 계통 연계 운영사와의 수익 공유 구조

### 4. 경쟁 구도 분석

- [ ] 국내외 경쟁사 3곳 이상 Feature·가격 비교표
- [ ] 특히 글로벌 독점 기업(Microsoft, Salesforce, Siemens, GE 등) 대비 차별화
- [ ] 고객 전환 비용(Switching Cost) 극복 전략
- [ ] 국산 대체재로서의 국가 안보·데이터 주권 관점 강조 여부

### 5. 글로벌 진출 계획

- [ ] 글로벌 표준 기술 채택 (IEC, IEEE, W3C 등)
- [ ] 해외 파트너사·총판·거점 계획
- [ ] 수출 목표 (금액·국가·연도별)
- [ ] 해외 인증 획득 계획 (CE, FCC, UL 등)

### 6. 정책 테마와의 연결

해당 과제가 정부 정책의 어떤 테마에 기여하는지 명시:
- [ ] 탄소 중립 / 2050 NetZero
- [ ] 중대재해 예방
- [ ] 디지털 전환 / K-클라우드
- [ ] AI 반도체 / K-반도체 전략
- [ ] 스마트 제조 7대 전략 분야
- [ ] 공급망 안정화 / 국산화

## 도메인별 핵심 킬러 질문 (DX/비즈니스)

- "타겟 시장에 이미 글로벌 독점 기업이 존재하는데, 가격 경쟁이나 기능 차별화 없이 고객 전환 비용을 어떻게 극복할 것인가?"
- "과제 종료 후 3년간 누적 매출 목표 달성을 위한 연도별 고객 수·ARPU·Churn 가정은 현실적인가?"
- "수요 기업이 과제 종료 후에도 지속 구매할 근거는 무엇인가? 단가 경쟁력 외 락인(lock-in) 요인은?"
- "수익 모델이 정부 SaaS 지원 목적과 정합하는가? (설치형 라이선스 모델은 부적합)"

## 진행 절차

1. DX/비즈니스 페르소나를 기본 호출, 도메인 2차 페르소나 추가 호출 여부 질의
2. 수요 확약·시장 규모·수익 모델 각각 🟢/🟡/🔴 판정
3. 🔴 발견 시 대응안 협의 후 Phase 4 진입

## 🔴 차단 이슈 기준

- 수요 기업 확약 전무
- 시장 규모 산출 근거 없음
- 수익 모델이 정부 지원 목적과 상충 (예: SaaS 과제인데 영구 라이선스)
- 경쟁사 분석이 아예 없음
