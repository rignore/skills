# 계산 수식 작성 패턴

사용자 경험에 영향을 주는 로직은 반드시 수식 섹션을 작성한다. PRD 안에서 수식은 **단계적 서술형 + 번호 계층**으로 작성한다. 코드처럼 쓰지 않는다.

## 수식 작성이 필요한 대상

| 카테고리 | 예시 |
|---|---|
| **임계치/이상치 판정** | 이상 감지, 알림 발송 기준, 필터링 조건 |
| **점수·우선순위 산출** | 추천 점수, 위험도 등급, 랭킹 |
| **데이터 전처리·집계·통계** | 평균, 표준편차, 변화율, 이동평균 |
| **차트·시각화 표시 정책** | 축 범위, 눈금 간격, 정렬 기준 |
| **추천·매칭 로직** | 유사도 계산, 가중치 적용 |

## 표준 양식

```
[정책명]
한 줄 설명 — 무엇을 계산하는지 + 왜 필요한지

[A. 핵심 계산]
1. 1단계 작업명
   1-a. 세부 작업: 서술형 설명
   1-b. 계산식: 단어 기반 수식
        예시: 수치 대입 결과

2. 2단계 작업명
   2-a. ...

[B. 예외 처리]
- 조건 1일 경우 처리 방법
- 조건 2일 경우 처리 방법

[C. 사용 시점 / 갱신 주기]
- 언제 계산되는가
- 결과는 어디서 사용되는가
```

## 작성 원칙

### 1. 코드가 아닌 서술형

❌ **나쁜 예**
```
mean = sum(values) / len(values)
threshold = mean + 2 * std
```

✅ **좋은 예**
```
1. 평균값 계산
   1-a. 데이터 값의 총합 계산
   1-b. 평균값 = (데이터 값의 총합) / (데이터 건수)

2. 임계치 계산
   2-a. 임계치 = 평균값 + (2 × 표준편차)
```

### 2. 변수 이름은 한국어 단어로

❌ `userId`, `eventCount`, `threshold`
✅ "사용자 식별 정보", "이벤트 발생 건수", "임계치"

### 3. 예시 수치는 별도 줄로

```
1-b. 임계치 = 평균값 + (2 × 표준편차)
     예시: 평균 50, 표준편차 5인 경우 → 임계치 = 60
```

### 4. 수학 함수는 풀어쓰기 + 괄호로 함수명 병기

- "내림 처리(floor)", "올림 처리(ceil)", "절댓값(abs)"
- "로그 계산(log10)", "제곱근(√)", "거듭제곱(²)"

### 5. 예외 처리 분리

수식 본문과 예외 케이스는 항상 별도 섹션으로 분리한다.

## 작성 예시 1 — 차트 Y축 정책

```
[Y축 범위 자동 계산 정책]
차트에 표시되는 데이터 기준으로 Y축 최솟값·최댓값·눈금 개수를 계산한다.
사용자가 값의 차이를 직관적으로 비교할 수 있도록 적절한 여백과 눈금 간격을 자동 산출한다.

[A. 데이터 범위 및 여백 적용]
1. 데이터셋 범위 계산
   1-a. 범위 = 데이터의 최댓값 - 최솟값

2. 여백(Padding) 적용
   2-a. 여백 값 = 범위 × 0.1
   2-b. 여백 적용 최댓값 = 데이터 최댓값 + 여백 값
   2-c. 여백 적용 최솟값 = 데이터 최솟값 - 여백 값

[B. 눈금 간격 계산]
1. 기본 간격 산출
   1-a. 여백 적용 범위 = 여백 적용 최댓값 - 여백 적용 최솟값
   1-b. 기본 간격 = 여백 적용 범위 / 5

2. 간격 자릿수 단위 산출
   2-a. 로그 계산: log10(기본 간격)
        예시: log10(12) = 1.0792
   2-b. 내림 처리: floor(로그 계산 결과)
        예시: floor(1.0792) = 1
   2-c. 자릿수 단위 = 10^(내림 처리 결과)
        예시: 10^1 = 10

3. 적정 눈금 배수 결정
   3-a. 정규화 값 = 기본 간격 / 자릿수 단위
   3-b. 배수 기준
        - 정규화 값 ≤ 1 → 배수 1
        - 정규화 값 ≤ 2 → 배수 2
        - 정규화 값 ≤ 5 → 배수 5
        - 정규화 값 > 5 → 배수 10
   3-c. 눈금 간격 = 배수 기준 × 자릿수 단위

[C. Y축 범위 확정]
1. Y축 최솟값 = floor(여백 적용 최솟값 / 눈금 간격) × 눈금 간격
2. Y축 최댓값 = ceil(여백 적용 최댓값 / 눈금 간격) × 눈금 간격
3. 눈금 개수 = (Y축 최댓값 - Y축 최솟값) / 눈금 간격 + 1

[D. 예외 처리]
- null 값이 있을 경우: 해당 값을 최솟값 0으로 처리
- 모든 데이터 값이 동일한 경우: 차트 라이브러리 내부 기본 기준 사용
- 모든 데이터 값이 0 이상인 경우(음수 없음): 눈금 개수 계산 전 Y축 최솟값을 0으로 변경
```

## 작성 예시 2 — 이상 감지 (EWMA 기반)

```
[주문량 급감 감지 정책]
실제 주문량이 예측된 기대치보다 지속적으로 부족할 경우, 그 추세를 EWMA(지수가중이동평균)로 추적하여 통계적 임계치를 넘으면 '주문량 이상 감소'로 감지한다.

[A. EWMA 계산]
1. 현재 오차 계산
   1-a. 현재 오차 = 예측값 - 실측값

2. EWMA(오차 추세) 계산
   2-a. EWMA = (평활도 × 현재 오차) + (1 - 평활도) × 이전 시점의 EWMA

3. 임계치 계산
   3-a. 임계치 = K값 × 오차 표준편차
   3-b. 오차 표준편차 산출에 사용되는 데이터: 최근 7일간의 (예측값 - 실측값)

[B. 이벤트 발생 조건]
- 실시간으로 갱신된 EWMA가 임계치를 초과할 경우 이벤트 발생

[C. 예외 처리]
- 감지 실행 후 가장 처음 데이터의 경우: 위 로직 대신 "예측값 - 실측값" 값 그대로 사용

[D. 사용 시점]
- 실시간 데이터 수집 시마다 EWMA 갱신
- 최근 7일 데이터 윈도우는 매일 자정 기준으로 슬라이딩
```

## 작성 예시 3 — 데이터 전처리 (이상치 제거)

```
[지표 데이터 전처리 정책]
당일 수집된 지표 데이터 중 이상치를 제거하여 다음날 평균·표준편차 계산에 사용한다.

[A. 1차 필터링 — 동일 값 반복 제거]
1. 24:00 시점에 당일 수집된 지표 데이터 중 5분 이상 측정 항목별로 동일한 값이 반복될 경우 해당 값 전체 제거
   1-a. 0이 정상인 경우는 별도 지정 후 포함 (예: 심야 시간대 주문 건수)

2. 유효 데이터 비율 확인
   2-a. 유효 데이터 비율 = (1차 필터링 후 데이터 개수) / (전체 데이터 개수)
   2-b. 유효 데이터 비율 ≤ 0.1인 경우: 평균·표준편차 계산 진행하지 않음
   2-c. 유효 데이터 비율 > 0.1인 경우: B 단계로 진행

[B. 2차 필터링 — 상하위 25% 제거]
1. 1차 필터링 후 데이터의 상위 25%, 하위 25% 값 제거

[C. IQR 방식 (옵션)]
1. 사전 정의
   1-a. 데이터 개수 = N (1차 필터링 후 데이터 개수)
   1-b. Q1 = (N + 1) / 4
   1-c. Q3 = 3 × (N + 1) / 4
   1-d. IQR = Q3 - Q1

2. 이상치 제거
   2-a. 지표값을 오름차순 정렬 후 1부터 순차적으로 숫자 부여
        ※ 0부터 부여하지 않음, 별도 컬럼 부여 불필요
   2-b. 부여된 숫자가 (Q1 - 1.5 × IQR) 이하인 데이터 제거
   2-c. 부여된 숫자가 (Q3 + 1.5 × IQR) 이상인 데이터 제거

[D. 사용 시점]
- 매일 24:00 정각 일괄 실행
- 결과는 다음날 평균값·표준편차 계산의 입력으로 사용
```

## 체크리스트

수식 작성 후 다음 항목을 확인:

- [ ] 모든 변수가 한국어 서술형으로 표현되었는가
- [ ] 단계가 번호 계층으로 명확히 분리되었는가
- [ ] 핵심 계산과 예외 처리가 별도 섹션으로 분리되었는가
- [ ] 사용 시점·갱신 주기가 명시되었는가
- [ ] 예시 수치가 적어도 한 곳에 포함되었는가
- [ ] 수학 함수가 풀어쓰기로 표현되었는가
