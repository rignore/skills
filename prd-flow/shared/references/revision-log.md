# PRD 작성 정책 변경 기록

## 2026-10-04 — PRD-STRUCT-003 배포

- 공통 경로의 승인된 Full PRD 정책을 배포 저장소에 반영했다. 문제는 개조식 4열 표로 작성하고 근거와 검증할 가설을 분리한다. 문서는 현재 목적·범위·정책이 독립적으로 이해되게 하며 불필요한 작성 맥락은 변경 기록·근거 문서에서 관리한다. 식별자만으로 본문 의미를 대신하지 않는다.
- KPI는 기본 3개, `KPI / 정의 / 측정 방법`으로 작성한다. 기준선·3/6개월 목표는 기본 열에서 제외한다. 관찰·계산할 수 있는 지표의 선정 예시를 제공하되 프로젝트에 그대로 복사하지 않는다.
- Epic 소제목은 적용 대상·상황·문제 또는 보장할 상태·동작과 결과를 의미 중심으로 완결한다. 사용자·운영·시스템 요구사항을 지원하며 문형·콜론·글자 수를 강제하지 않는다. Epic 이름·개수·산출물 책임 경계는 별도 기준으로 유지한다.
- 활성 PRD 작성·검토·Notion 경로의 1-Pager 정책과 템플릿을 제거했다. 정책 정본은 Full PRD 템플릿과 Epic 작성 기준 §4이며 다른 진입점은 이를 참조한다.
- 공통 경로의 미배포 변경 전체를 복사하지 않았다. 이 저장소에 없는 폐기된 순차 작성 스킬과 요약 정책이 없는 editorial-reviewer는 추가·교체하지 않았다.
- 검증: 스킬 메타데이터, 활성 폐기 정책 잔존, 참조 경로, diff를 검사한다. 실제 PRD 전체 자동 생성 시험은 수행하지 않는다.
