# General UX Writing

서비스 UI 텍스트 작성 가이드. prd-flow 스킬 세트의 **표준 UX writing 룰북**으로, 모든 화면 텍스트 작성에 기본 적용된다.

## 이 스킬의 위치

- 모든 화면 텍스트(와이어프레임·디스크립션·프로토타입)의 **기본 UX writing 소스**는 본 스킬이다. `context.json`의 `ux_writing_skill` 필드가 이 스킬을 가리킨다.
- 호출은 `prd-to-wireframe`·`inspection-mode`·`wireframe-description`이 화면 텍스트 작성 시 자동 적재한다. 사용자가 직접 호출해 "이 카피 검토해줘"라고 요청할 수도 있다.
- 도메인 고유의 보이스·톤이 별도로 정의된 프로젝트라면, 본 스킬의 원칙 위에 그 프로젝트의 용어 매트릭스를 얹어 사용한다.

## 호출 트리거

- 버튼·라벨·알림·에러·placeholder·helper·빈 상태·토스트·모달 등 UI 텍스트 작성·검토 요청
- "UX writing 가이드", "마이크로카피", "카피 톤 점검" 류 표현
- prd-flow 화면 생성·수정 단계 (호출 스킬이 자동 적재)

## 핵심 원칙 (7개 섹션)

본 스킬의 룰북(`references/ux-writing.md`)은 7개 섹션으로 구성된다:

1. **코어 밸류 4가지**: "명확한·전문적인·책임감 있는·일관적인" — 도메인과 무관하게 보편적으로 유효
2. **메시지 3요소 (A·B·C)**: 현재 상황 / 영향 / 필수 행동 — 알림·경고는 최소 2개 조합
3. **어조 분리 3종**: 명사형 / `~이 필요합니다` / `~해주세요`
4. **라이팅 실행 원칙 4가지**: 행동 유도 · 간결성 · 진단/위험 고지 · 불확실성 제어
5. **화면 유형별 가이드 5종**: 폼 · 알림 · 빈 상태 · 확인 모달 · 토스트
6. **자가 검증 5단계**: 모든 카피가 통과해야 하는 체크리스트
7. **정답 카피 패턴**: 일반 SaaS 화면에서 그대로 차용 가능한 패턴 모음

용어 매트릭스는 강제하지 않는다 — 프로젝트별로 자체 용어 사전(`docs/glossary.md` 등)을 누적하는 것을 권고한다 (상세: `references/ux-writing.md` §4-2).

## Phase 0 — 작업 착수 전 확인

UX writing 작업 의뢰가 들어오면 먼저 확인:

1. **작성 대상 카피 유형**: 버튼·라벨 / 알림·경고 / 에러 / placeholder·helper / 빈 상태 / 토스트 / 모달 (복수 선택 가능)
2. **프로젝트 도메인**: 결제·이커머스 / SaaS B2B / 콘텐츠 / 소셜 / 생산성 도구 등 (도메인 예시 선택에 사용)
3. **언어**: 한국어 기본 / 영문 / 둘 다
4. **기존 카피 자산 유무**: 프로젝트에 이미 정의된 용어 매트릭스가 있다면 적재

## Phase 1 — 적용

`references/ux-writing.md`를 컨텍스트에 적재한 뒤 작성·검토 수행. 적재된 가이드의 7개 섹션을 순서대로 적용.

## Phase 2 — 자가 검증

`references/ux-writing.md`의 "Step 1~5 자가 검증 체크리스트"를 모든 카피에 대해 통과시킨다.

## 의존 스킬

| 스킬 | 역할 |
|---|---|
| `prd-to-wireframe` | 와이어프레임 텍스트 작성 시 본 스킬을 자동 적재 |
| `inspection-mode` | 디스크립션·챗봇 컨텍스트의 UX writing 규칙 참조 |
| `wireframe-description` | 디스크립션 카피 작성 시 참조 |
| `design-system-builder` | UX writing은 본 스킬, 비주얼·컴포넌트 규칙은 생성된 `design/design-system.md`. 분리 운영 |

## 확장 슬롯

도메인 특화 UX writing이 필요할 때 본 스킬을 기반으로 확장 가능:

- `{domain}-ux-writing` (특정 도메인 어휘·긴급도 표현 특화)
- `client-{name}-ux-writing` (외부 클라이언트별 보이스·톤)

확장 스킬은 본 스킬의 4가지 코어 밸류·3가지 어조 분리·메시지 3요소를 inherit하고 도메인 용어 매트릭스·예시만 교체하는 구조 권고.
