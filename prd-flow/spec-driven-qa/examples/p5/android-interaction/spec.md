## api-demos-app-opens
kind: acceptance_criterion
status: approved
title: Tapping App opens the App demo list

After the public ApiDemos APK launches, tapping the root list item App opens a list that contains Action Bar.

## api-demos-back-returns
kind: acceptance_criterion
status: approved
title: Android back returns to the root list

From the App demo list, Android back returns to the root list, where Accessibility is present.
