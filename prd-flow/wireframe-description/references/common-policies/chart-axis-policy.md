# 라인/바 차트 공통 정책

## 라인/바 차트 Y축 정책

### A. 최솟값이 0 이상인 경우

현재 차트에 표시되고 있는 데이터의 최댓값이 속한 숫자의 범위를 기준으로 Y축에 원점(0) 포함 7개 숫자 표시.

| 숫자 범위 (앞 초과 뒤 이하) | 숫자 표기 |
|------------------------|---------|
| 0 ~ 0.5 | 0.1의 배수 |
| 0.5 ~ 2.5 | 0.5의 배수 |
| 2.5 ~ 5 | 1의 배수 |
| 5 ~ 10 | 2의 배수 |
| 10 ~ 50 | 10의 배수 |
| 50 ~ 100 | 20의 배수 |
| 100 ~ 250 | 50의 배수 |
| 250 ~ 500 | 100의 배수 |
| 501 ~ 1,000 | 200의 배수 |
| 1,000 ~ 5,000 | 1,000의 배수 |
| 5,000 ~ 10,000 | 2,000의 배수 |
| 10,000 ~ 50,000 | 10,000의 배수 |
| 50,000 ~ 100,000 | 20,000의 배수 |

예시: 데이터 최댓값이 62일 경우 0, 20, 40, 60, 80, 100, 120 표시.

### B. 최솟값이 0 미만(음수)인 경우

현재 차트에 표시되고 있는 데이터의 최솟값과 최댓값을 기준으로 숫자 범위 계산.

- 숫자 범위: 최댓값 − 최솟값
- 해당 값이 속한 숫자의 범위를 기준으로 숫자 표기 기준 설정 (위 표 참고)
- 원점에 최솟값보다 작거나 같은 최소 배수 표시
- 원점 포함 Y축에 7개 숫자 표시

**예시**: 최솟값 -60, 최댓값 10 → 범위 70 → 20 배수 표기 → -60보다 작거나 같은 20의 최소 배수 = -60 → Y축: [-60, -40, -20, 0, 20, 40, 60]

*[백로그] 추후 값 변동의 가독성을 위해 최솟값·최댓값 활용 Y축 숫자 표기 범위 수정 예정.

## 시계열 라인 차트 Y축 정책 (지표 상세 팝업 등 정밀 차트)

### A. Y축 정책

현재 차트에 표시되고 있는 데이터 기준으로 Y축 최솟값, 최댓값, 눈금 개수 계산.

**데이터 범위 및 여백 적용**

1. 데이터셋 범위: 데이터의 최댓값 − 최솟값
2. Padding값: 계산된 현재 범위 × 0.1
3. 여백 적용: 최댓값 + Padding값, 최솟값 − Padding값

**눈금 간격 계산**

1. 여백 적용 범위: (여백 적용된) 최댓값 − 최솟값
2. 기본 간격: 여백 적용 범위 / 5
3. 간격 자리수 단위: `10^floor(log10(기본 간격))`
4. 간격 정규화: 기본 간격 / 간격 자리수 단위
5. 적정 눈금 배수 기준:
   - 정규화 값 ≤ 1 → 1
   - 정규화 값 ≤ 2 → 2
   - 정규화 값 ≤ 5 → 5
   - 정규화 값 > 5 → 10
6. 눈금 간격 = 적정 눈금 배수 × 간격 자리수 단위

**Y축 범위 계산**

- Y축 최솟값: `floor(여백 적용 최솟값 / 눈금간격) × 눈금간격`
- Y축 최댓값: `ceil(여백 적용 최댓값 / 눈금간격) × 눈금간격`
- 눈금 개수: `(Y축 최댓값 − Y축 최솟값) / 눈금간격 + 1`

### B. 예외 처리

- null값이 있을 경우 최솟값 0으로 처리
- 모든 데이터 값이 동일한 경우 차트 라이브러리 내부 기준 표시
- 모든 데이터값이 0 이상일 경우(음수 없을 경우) 눈금 개수 계산 전 Y축 최솟값을 0으로 변경

## X축 정책

숫자 표기는 정각(1시간 단위)만 표기.

**이벤트 상세 차트**: 해당 이벤트(예: 주문 급증 알림)의 발생 시간을 기준으로 4시간 이전, 2시간 이후까지 표시.

**실시간 데이터**: 현재 시간 기준 6시간 전 데이터 표시.
