# 데이터 테이블 정책

## A. 테이블 데이터 키워드 검색 정책

각 디스크립션에 정의된 컬럼에 대해 검색 키워드와 데이터가 연속된 2개 이상의 숫자/문자가 일치할 경우 화면에 표시.

검색 시 키워드 및 조회 대상인 데이터에 공백 제거.

---

## 데이터 정렬 기준 정책

사용자가 드롭다운 메뉴, 리스트, 테이블 등에서 데이터를 예측 가능하고 일관된 방식으로 찾을 수 있도록 공통 정렬 기준을 정의.

### A. 시스템 제공 데이터 정렬

대상: 사용자가 직접 등록하지 않고, 시스템에 미리 정의되어 있거나 외부(DB 등)에서 불러오는 항목. 사용자가 직접 등록하는 정보여도, 등록한 뒤 바로 표시되는 페이지가 아닌 경우도 해당됨.

예시: 태스크 등록 팝업의 "담당 팀" 셀렉박스, 멤버 초대 팝업의 "권한 등급" 목록 등.

정렬 기준: 문자열 기준 오름차순 (가나다순 / ABC순)

### B. 사용자 등록 데이터 정렬

대상: 사용자가 시스템 내에서 직접 생성하는 항목.

예시: 계정 관리 페이지의 계정 리스트, 프로젝트 상세 팝업의 태스크 리스트, 자동화 규칙 목록 등.

정렬 기준: 등록 시간 기준 내림차순 (최신순)

### C. 예외 및 기타

각 페이지의 데이터 테이블은 이 정책을 기본 정렬 기준으로 따르되, 사용자가 각 컬럼의 헤더를 클릭하여 오름차순/내림차순으로 재정렬할 수 있는 기능을 제공해야 함.
