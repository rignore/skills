# 스낵바 정책

## A. 오류 안내

생성 후 화면에 10초간 표시.

X 아이콘 클릭 시 스낵바 즉시 종료.

---

## B. 완료 안내

생성 후 화면에 3초간 표시.

---

## 오류 안내 스낵바 기본 정책

별도 디스크립션이 작성되어 있지 않을 경우, 정보 호출/등록에 실패 시 표시.

오류 안내 텍스트: `"{기능/정보 명}에 실패하였습니다.\n잠시 후 다시 시도해 주세요."`

---

## 디스크립션 작성 시 참조 방법

```markdown
데이터 호출 실패 시: 오류 안내 스낵바 정책 A 적용.
```

```markdown
저장 완료 시: 완료 안내 스낵바 정책 B 적용.
```
