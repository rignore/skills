# 셀렉박스 정책

## 셀렉박스 선택 영역이 잘리는 경우 정책

현재 스크롤 포지션 기준.

### A. 팝업 내부에서 생성되는 셀렉박스일 경우

셀렉박스 선택 영역이 팝업 밖으로 벗어날 경우 위쪽으로 생성.

### B. 기본 인터페이스에서 생성되는 경우

셀렉박스가 화면을 벗어날 경우 위쪽으로 생성.

---

## 전체 항목 정책

N개 선택 가능한 셀렉박스의 선택 항목 최상단에 항상 "전체" 항목 표시.
*단일 항목만 선택 가능한 셀렉박스 제외.

- 전체 항목 선택 시 선택 가능한 모든 항목 추가
- 필터링 셀렉박스의 경우 전체 항목이 포함된 초기 상태로 변경
