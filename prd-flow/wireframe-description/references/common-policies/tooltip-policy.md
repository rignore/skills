# 툴팁 정책

## 툴팁 인터랙션

### A. 단순 정보 요약 툴팁

툴팁 노출 이후 화면 아무 데나 클릭 시 툴팁 닫힘.

예시:
- 주문 현황 요약 카드 툴팁
- 시간대별 주문 건수 바차트 툴팁
- 매출 추이 팝업 라인 차트: 마커 툴팁

### B. 버튼이 있는 툴팁

툴팁 외 모든 영역 클릭 시 툴팁 닫힘.

예시:
- 칸반 보드 태스크 카드 툴팁 (상세 보기 버튼 포함)
- 대시보드 바차트 위젯 툴팁 (드릴다운 버튼 포함)

### C. 기능/개념 설명 툴팁

마우스 오버 시에만 툴팁 노출.

예시:
- 요금제 페이지: 플랜 등급, 사용량 지표 설명
- 대시보드: 위젯 설명 툴팁

---

## 디스크립션 작성 시 참조 방법

```markdown
[2-3] 정보 아이콘

툴팁 타입 C (기능/개념 설명) 적용. 마우스 오버 시 "{설명 텍스트}" 표시.
```

```markdown
[1-4] 태스크 카드

툴팁 타입 B (버튼 있음) 적용. 툴팁 내용 → (칸반 보드 설계서 [1-4] 참고)
```
