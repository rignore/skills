# 평균값·표준편차·변화율 계산 관련 정책

자동 수집되는 시계열 지표 데이터(예: 서버 응답 시간, 시간당 주문 건수, 습관 기록 수치 등)를 통계·차트 화면에서 사용하기 전의 전처리·집계 공통 정책.

## A. 데이터 전처리

24:00에 당일(00시~24시) 수집된 지표 데이터 중 상/하위 25% 값 제거.

*하단 데이터 전처리 방법은 시계열 DB 도입 이후 적용.*

**a.** 24:00에 당일 수집된 지표 데이터 중 5분 이상 지표별로 동일한 값이 반복될 경우 해당 값 전체 제거 (수집 장애로 인한 값 고착 가능성).
- *0이 정상인 지표는 별도 지정 후 포함 (예: 미처리 문의 건수)*

**b.** [a] 과정을 통해 나온 (유효 데이터 개수 / 전체 데이터 개수)의 값이 0.1을 초과할 경우 [c] 계산 진행.
- 0.1 이하일 경우 당일 평균값 및 표준편차 계산 진행 X

**c.** [b]의 결과값이 0.1 초과일 경우 [a]에서 제거된 값 제외한 데이터의 상/하위 25% 값 제거.

*추후 필요에 따라 IQR 방식 사용 이상치 제거.*

### IQR 계산식

사전 정의:
- N = [a]에서 제거된 값 제외한 데이터 개수
- Q1 = (N+1) / 4
- Q3 = 3(N+1) / 4
- IQR = Q3 − Q1

계산법:
1. 지표값 오름차순 정렬 후 1부터 순차적으로 숫자 부여 (*0부터 부여 X*)
2. [i]에서 부여된 숫자가 Q1 − 1.5×IQR보다 같거나 작은 데이터 제거
3. [i]에서 부여된 숫자가 Q3 + 1.5×IQR보다 같거나 큰 데이터 제거

## B. 평균값 계산

당일 전처리된 지표 데이터의 평균값 계산 후 다음날 사용.

`평균값 = 전처리된 데이터 값의 총합 / 데이터 건수`

이후 당일 지표 데이터의 평균값 및 계산에 사용된 데이터 건수 저장.

*하단 N일 동안 평균값은 시계열 DB로 변경 후 적용.*

지표별 평균값 계산 방식:
```
{(저장된 날짜별 지표 평균값 × 날짜별 데이터 건수)의 총합} / (n일간 발생한 데이터 건수 총합)
```
*n일: 현재까지 지표 평균값 및 데이터 건수가 저장된 기간 또는 365일 중 더 작은 숫자.*

## C. 표준편차 계산

당일 전처리된 지표 데이터의 표준편차 계산 후 다음날 사용.

표준편차 계산식:
1. `(각 지표값 − 당일 평균값)²`
2. [a] 결과값의 총합(sum)
3. [b] / 데이터 건수
4. [c]의 제곱근 = 당일 지표 데이터의 표준편차

*하단 N일 동안 표준편차는 시계열 DB로 변경 후 적용.*

n일 표준편차 계산:
1. `날짜별 데이터 건수 × {날짜별 표준편차² + (날짜별 평균값 − n일 평균값)²}`
2. [a] 결과값의 총합(sum)
3. [b] / n일 동안의 데이터 건수 총합
4. [c]의 제곱근 = n일 동안의 지표 데이터 표준편차

## D. 변화율 계산

당일 전처리된 데이터에 대한 변화율 계산 후 지정된 백분위수별 변화율 산출 (급증/급감 알림 임계치 등에 사용).

*지정된 백분위수: 90, 92, 94, 96, 98, 100*

변화율 계산식:
1. [A. 데이터 전처리] 정책에 따라 당일 전처리된 지표 데이터 준비
2. 전처리된 데이터를 기반으로 1일간의 모든 변화율(dP/dt) 계산: `변화율 = (현재 값 - 이전 값) / (현재 시간 - 이전 시간)`
3. 계산된 모든 변화율 오름차순 정렬
4. 정렬된 값들 중에서 지정된 백분위수 값을 찾아 당일 데이터에 대한 백분위수별 변화율 저장
5. n일간(최대 7일) 백분위수별 변화율 평균값 계산하여 임계치로 사용:
   - 최근 7일간 백분위수별 변화율 호출 후 평균 계산
