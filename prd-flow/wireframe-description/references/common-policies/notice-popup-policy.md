# 안내 팝업 정책

## 기본 정책

안내 팝업은 표시되는 정보를 확인 후 행동을 결정해야 하므로, 팝업 이외 영역 클릭 또는 [ESC] 입력으로 팝업이 닫히지 않도록 개발.

안내 팝업의 예시: 로그아웃 확인 팝업, 계정 삭제 팝업, 프로젝트 담당자 지정 안내 팝업 등.

*이메일 발송 완료 안내 팝업과 같이 정보 안내 대안이 있는 경우 스낵바로 점진적으로 변경.

---

## 요청 대기 중 안내 팝업

대용량 주문 데이터 내보내기 처리 중 안내 팝업 등 사용자가 요청한 작업을 처리하는 중임을 안내하는 팝업. 지정된 API에만 적용.

- 사용자의 요청 후 응답 받기 전 또는 timeout error가 발생하기 전까지 표시
- timeout error 두 가지 타입 (API 개발하는 사람이 판단):
  - 평균 응답 시간이 짧은 경우: 30초 제한
  - 평균 응답 시간이 길 가능성이 있는 경우: 5분 제한
- timeout error 발생 시 오류 안내 스낵바 화면에 표시 (`snackbar-policy.md` 참조)

*[백로그] 추후 실행 취소 버튼 넣을지 말지 고민.
