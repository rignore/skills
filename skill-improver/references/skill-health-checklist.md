# SKILL.md 품질 기준 체크리스트

Phase 4에서 수정안 적용 전, 그리고 신규 스킬 작성 시 이 체크리스트로 검증한다.

---

## 필수 구조 체크 (모든 스킬 공통)

```
[ ] frontmatter에 name, description 필드 있음
[ ] description이 한 문단으로 스킬의 목적·대상·트리거 조건을 모두 담음
[ ] ## 핵심 원칙 섹션 존재
[ ] ## 워크플로우 / Phase 구조 존재
[ ] Phase 0 — 시작 전 확인 또는 동등한 세팅 단계 존재
[ ] ## 트리거 키워드 섹션 존재 (또는 description에 통합)
[ ] ## 다른 스킬과의 관계 섹션 존재
[ ] references 파일이 필요한 경우 적재 규칙이 명시됨
```

---

## description 품질 체크

```
[ ] 스킬 이름만으로 목적을 알 수 있음 (불필요한 반복 없음)
[ ] 트리거 키워드 예시가 최소 5개 이상 포함됨
[ ] "이 스킬을 사용하지 않는 경우"가 명시되거나 다른 스킬과의 경계가 명확함
[ ] 200자 이상 500자 이내 (너무 짧으면 트리거 미발동, 너무 길면 노이즈)
```

---

## 트리거 키워드 품질 체크

```
[ ] 직접 표현 (명사형): "PRD 작성", "스킬 개선" 등
[ ] 간접 표현 (의도형): "처음부터 단계별로", "검토해줘" 등
[ ] 영문 표현 포함 (사용자가 영문 혼용 시 대응)
[ ] 다른 스킬과 겹치는 키워드에 경계 조건 명시
    예: "PRD 검토" → prd-builder 트리거 / 단, 이미 완성된 PRD 수정은 editorial-reviewer
[ ] 부정 트리거 명시: 이 키워드가 있어도 발동하지 않는 조건
```

---

## Phase 구조 품질 체크

```
[ ] 각 Phase에 구체적인 입력(Input)과 출력(Output) 형식 정의
[ ] Phase 간 전환 조건 명시 (컨펌 필요 여부)
[ ] 건너뛸 수 있는 Phase와 필수 Phase 구분
[ ] 오류/예외 처리 규칙 (예: "사용자가 답변 없으면 기본값으로 진행")
[ ] 각 Phase가 단일 책임을 가짐 (한 Phase가 너무 많은 것을 함)
```

---

## 레퍼런스 파일 품질 체크

```
[ ] references/ 폴더가 있으면 SKILL.md에 적재 규칙 표가 있음
[ ] 조건부 파일(특정 작업 유형에만 필요)과 필수 파일이 구분됨
[ ] 각 references 파일의 용도가 한 줄로 명시됨
[ ] 더 이상 사용하지 않는 references 파일이 남아있지 않음
```

---

## 페르소나 시스템 품질 체크 (페르소나를 사용하는 스킬만)

```
[ ] 각 페르소나의 전문 영역이 겹치지 않음
[ ] 페르소나별 라우팅 기준(어느 Phase에서 호출)이 명시됨
[ ] 조건부 페르소나의 호출 조건이 명확함
[ ] 페르소나 출력 형식(헤더, 강점/보완/차단 구조 등)이 통일됨
[ ] 페르소나 reference 파일에 말투·관점이 충분히 정의됨
```

---

## 가드레일 품질 체크

```
[ ] 스킬이 해서는 안 되는 행동이 명시됨 (예: 화살표 금지, hex 색상 금지)
[ ] 가드레일마다 위반 예시와 올바른 예시가 짝을 이룸
[ ] 자가 검증 체크리스트가 있음 (design-token-sync의 VERIFICATION STEP 방식)
```

---

## 스킬 간 관계 품질 체크

```
[ ] 이 스킬 전에 실행되면 좋은 스킬 명시
[ ] 이 스킬 후에 실행되면 좋은 스킬 명시
[ ] 이 스킬과 혼동될 수 있는 스킬 명시 + 경계 조건
[ ] 권장 워크플로우 체인이 있으면 mermaid 또는 텍스트 다이어그램으로 표현
```

## 안티패턴 (SKILL.md 작성 시 피해야 할 것)

- **과도한 일반화**: "사용자가 뭔가를 만들어달라고 하면" → 구체적 키워드로 대체
- **중복 트리거**: 다른 스킬과 동일한 키워드 → 우선순위 또는 경계 조건 추가
- **Phase 없는 스킬**: 작업이 복잡한데 Phase 구조 없이 자유 형식 → 최소 3단계로 구조화
- **references 명시 없는 파일 참조**: "references를 읽는다"는 있으나 어떤 파일인지 불명 → 표로 명시
- **할루시네이션 방지 규칙 부재**: 외부 지식을 다루는 스킬에서 "없는 정보 추가 금지" 누락
